## Engines（引擎）

### 模块概述

`engines` 提供与脚本环境、多脚本并发执行相关的能力：在新引擎/新线程中执行字符串脚本、JS 文件、录制文件；查询当前引擎与全部运行中引擎；停止全部脚本等。新环境与当前脚本的变量不共享。

### 源码定位

| 角色 | 路径 |
|------|------|
| Rhino 桥接（`selfAssignmentFunctions` 等） | `app/src/main/java/org/autojs/autojs/runtime/api/augment/engines/Engines.kt` |
| 运行时封装（委托 `ScriptEngineService`） | `app/src/main/java/org/autojs/autojs/runtime/api/Engines.kt` |
| 引擎服务（执行、停止、全局监听） | `app/src/main/java/org/autojs/autojs/engine/ScriptEngineService.java` |
| 注册到全局作用域 | `app/src/main/java/org/autojs/autojs/runtime/ScriptRuntime.kt`（`Engines(this).augment(target, true)`，约第 796 行） |

桥接层暴露的自有赋值函数见：

### API 列表总览

| API | 说明 |
|-----|------|
| `execScript(name, script[, config])` | 在新环境中执行脚本字符串 |
| `execScriptFile(path[, config])` | 在新环境中执行脚本文件 |
| `execAutoFile(path[, config])` | 在新环境中执行 `.auto` 录制文件 |
| `myEngine()` | 当前脚本的 JavaScript 引擎实例 |
| `all()` | 当前所有运行中引擎的数组 |
| `getEngines()` | 引擎集合（与 `all()` 数据源一致，见实现） |
| `stopAll()` | 停止所有脚本（含自身） |
| `stopAllAndToast()` | 停止全部并 Toast 提示数量 |

### 详细 API

#### `engines.execScript(name, script[, config])`

- **参数**
  - `name`（string）：任务显示名，与文件名无关。
  - `script`（string）：脚本内容。
  - `config`（object，可选）：`delay`、`loopTimes`、`interval`、`path` / `workingDirectory`、`arguments`（见 `Engines.kt` 中 `fillConfig`）。
- **返回值**：`ScriptExecution`（官方文档）；实现侧为 `org.autojs.autojs.execution.ScriptExecution`。
- **源码定位**：`Engines.kt` 中 `execScript` → `scriptRuntime.engines.execScript`；`Engines.kt`（runtime）`execScript` → `ScriptEngineService.execute`。
- **示例**

```js
engines.execScript("hello", "toast('hello world')");
engines.execScript("loop", "toast('tick')", { loopTimes: 10, interval: 3000 });
```

#### `engines.execScriptFile(path[, config])`

- **参数**：`path`（string）；`config`（object，可选），字段同上。
- **返回值**：`ScriptExecution`。
- **源码定位**：`Engines.kt`（augment）→ `Engines.kt`（runtime）`execScriptFile` → `JavaScriptFileSource` + `ScriptEngineService.execute`。
- **示例**

```js
engines.execScriptFile("/sdcard/scripts/task.js");
```

#### `engines.execAutoFile(path[, config])`

- **参数**：`path`（string）；`config`（object，可选）。
- **返回值**：`ScriptExecution`。
- **源码定位**：`AutoFileSource` + `ScriptEngineService.execute`（见 `Engines.kt` runtime）。
- **示例**

```js
engines.execAutoFile("/sdcard/scripts/record.auto");
```

#### `engines.myEngine()`

- **参数**：无。
- **返回值**：当前 `JavaScriptEngine`；可通过 `execArgv` 等获取运行参数（参见官方 engines 文档）。
- **源码定位**：`Engines.kt`（augment）`myEngine` → `Engines.kt`（runtime）`myEngine()`。
- **示例**

```js
toast(engines.myEngine().cwd());
log(engines.myEngine().execArgv);
```

#### `engines.all()`

- **参数**：无。
- **返回值**：`NativeArray`，元素为运行中的脚本引擎。
- **源码定位**：`Engines.kt`（runtime）`all()` → `engines.toNativeArray()`。
- **示例**

```js
log(engines.all());
```

#### `engines.stopAll()` / `engines.stopAllAndToast()`

- **参数**：无。
- **返回值**：`Int`，表示停止的脚本数量相关结果（实现委托 `ScriptEngineService.stopAll` / `stopAllAndToast`）。
- **源码定位**：`ScriptEngineService.java` 第 196–206 行附近。
- **示例**

```js
engines.stopAll();
engines.stopAllAndToast();
```

#### 相关类型（官方文档）

- **ScriptExecution**：`getEngine()`、`getConfig()`；停止执行可用 `execution.getEngine().forceStop()`。
- **ScriptEngine**：`cwd()`、`getSource()`、`emit(eventName[, ...args])`（跨脚本事件，与 `events` 配合）。

## Modules（模块）

### 模块概述

Auto.js 系运行时支持基于文件的简单模块系统：一个文件对应一个模块，使用 `require` 加载，`module.exports` 导出。模块内变量默认对外不可见。

### 源码定位

- 全局 `require` 由 Rhino 运行时注入（参见 `ScriptRuntime` 中 `rhinoRequire` 相关逻辑）；**无单独 `modules` 桥接类**。
- 与 **Engines** 的 `config.path` / `workingDirectory` 共同影响模块查找路径。

### API 列表总览

| 概念 | 说明 |
|------|------|
| `require(id)` | 加载同项目或配置路径下的模块文件 |
| `module.exports` | 导出对象或函数 |
| `exports` | 与 `module.exports` 配合（勿仅给 `exports` 重新赋值） |

### 详细说明（示例）

- **参数**：`require` 的参数为模块路径字符串（实现依运行时解析规则）。
- **返回值**：被导出对象。
- **源码定位**：Rhino 顶层 `require`（非本文件列表中的独立 `modules.kt`）。
- **示例**（摘自官方 [modules 文档](https://docs.autojs6.com/modules)）

```js
// circle.js
const PI = Math.PI;
var circle = {};
circle.area = function (r) { return PI * r * r; };
module.exports = circle;

// foo.js
var circle = require("circle.js");
console.log(circle.area(4));
```

## Threads（线程）

### 模块概述

在独立线程中执行脚本逻辑；主线程会等待子线程结束（若子线程死循环需 `exit()` 或 `threads.shutDownAll()`）。可通过原子量、锁、`disposable` 等做简单同步与线程间一次性结果传递。

### 详细 API

#### `threads.start(action)`

- **参数**：`action`（function）。
- **返回值**：线程控制对象（文档称 `Thread`；实现为 `TimerThread` 等）。
- **源码定位**：`Threads.kt`（augment）→ `Threads.kt`（runtime）`start`。
- **示例**


#### `threads.currentThread()`

- **参数**：无。
- **返回值**：当前线程；若在脚本主线程则返回 `MainThreadProxy`（见 runtime `Threads.kt`）。
- **源码定位**：`Threads.kt`（runtime）第 79–85 行 `currentThread()`。
- **示例**

```js
log(threads.currentThread());
```

#### `threads.atomic([initialValue])`

- **参数**：`initialValue`（number，可选），默认 `0`。
- **返回值**：`java.util.concurrent.atomic.AtomicLong`。
- **源码定位**：`Threads.kt`（runtime）`atomic`。
- **示例**

```js
var i = threads.atomic();
threads.start(function () { log(i.getAndIncrement()); });
```

#### `threads.lock()`

- **参数**：无。
- **返回值**：`java.util.concurrent.locks.ReentrantLock`。
- **源码定位**：`Threads.kt`（runtime）`lock()`。
- **示例**

```js
var lock = threads.lock();

try { /* 临界区 */ } finally { lock.unlock(); }
```

#### `threads.disposable()`

- **参数**：无。
- **返回值**：`VolatileDisposeNativeObject`，含 `setAndNotify`、`blockedGet`、`blockedGetOrThrow`。
- **源码定位**：`VolatileDisposeNativeObject.kt`；`Threads.kt`（augment）`disposable`。
- **示例**

```js

threads.start(function () { d.setAndNotify(42); });
toast("result = " + d.blockedGet());
```

- **参数**：`callback`；可选附加参数。
- **返回值**：id，供 `clearImmediate` 使用。
- **源码定位**：`Timers.kt` `setImmediate`。
- **示例**

```js

```

## Events（事件监听）

### 模块概述

监听通知、按键、Toast、触摸等；`events` 本身是 `EventEmitter`，并内置多种系统事件。事件在单线程队列中处理，耗时逻辑会阻塞后续事件。

### 源码定位

| 角色 | 路径 |

| 核心实现 | `app/src/main/java/org/autojs/autojs/runtime/api/Events.java`（继承 `EventEmitter`） |

### API 列表总览

| API | 说明 |
|-----|------|
| `on` / `off` / `emit` | `EventEmitter` 标准方法（继承链） |
| `observeKey` | 开启按键监听（无障碍） |
| `onKeyDown` / `onKeyUp` | 指定键按下/抬起 |
| `observeNotification` / `observeToast` | 通知栏 / Toast |
| `onNotification` / `onToast` | 便捷注册 |
| `events.broadcast` | 脚本间广播（`BroadcastEmitter`） |
| `removeAllListeners([eventName])` | 移除监听 |

### 详细 API

#### `events.on(eventName, listener)`

- **参数**：`eventName`（string 或 symbol）；`listener`（function）。
- **返回值**：`EventEmitter`（可链式）。
- **源码定位**：`EventEmitter.java` `on`。
- **示例**

```js
events.on("my_event", function (x) { log(x); });
```

#### `events.off(eventName[, listener])`

- **参数**：事件名；若传入 `listener` 则只移除该回调，否则行为以 `EventEmitter` 实现为准。
- **返回值**：`EventEmitter`。
- **源码定位**：`EventEmitter.java` `removeListener` / `off`。
- **示例**

```js
function h() {}
events.on("e", h);
events.off("e", h);
```

#### `events.emit(eventName[, ...args])`

- **参数**：事件名；任意附加参数传给监听器。
- **返回值**：`boolean`，是否有监听器被调用。
- **源码定位**：`EventEmitter.java` `emit`。
- **示例**

```js
events.emit("my_event", 123);
```

#### `events.removeAllListeners([eventName])`

- **参数**：可选 `eventName`；省略则移除全部事件监听。
- **返回值**：`EventEmitter`。
- **源码定位**：`EventEmitter.java` `removeAllListeners`。
- **示例**

```js
events.removeAllListeners("my_event");
events.removeAllListeners();
```

#### `events.observeKey()`

- **参数**：无。
- **返回值**：`void`；未开无障碍会抛错（见 `Events.java`）。
- **源码定位**：`Events.java` `observeKey`。
- **示例**

```js
events.observeKey();
events.onKeyDown("volume_up", function (e) { log(e); });
```

#### `events.onKeyDown(keyName, listener)` / `events.onKeyUp(keyName, listener)`

- **参数**：`keyName`（string）；`listener`（function，参数为 `KeyEvent`）。
- **返回值**：`Events`（链式）。
- **源码定位**：`Events.java`。
- **示例**

```js
events.observeKey();
events.onKeyDown("volume_up", function (event) { toast("down"); });
```

#### `events.observeNotification()`

- **参数**：无。
- **返回值**：void；若通知监听服务未就绪可能重试绑定或打开系统设置页（见 `Events.java`）。
- **源码定位**：`Events.java` `observeNotification`。
- **示例**

```js
events.observeNotification();
events.on("notification", function (n) {
  log(n.getTitle(), n.getText());
});
```

#### `events.observeToast()`

- **参数**：无。
- **返回值**：void；依赖无障碍服务。
- **源码定位**：`Events.java` `observeToast`。
- **示例**

```js
events.observeToast();
events.onToast(function (toast) {
  log(toast.getText(), toast.getPackageName());
});
```

#### `events.broadcast`（脚本间广播）

- **说明**：`events.broadcast` 为 `BroadcastEmitter`，对外仍使用标准 `on` / `emit`；内部收包路径会调用 `onBroadcast`（见 `BroadcastEmitter.java`）。
- **参数 / 返回值**：与 `EventEmitter` 相同。
- **源码定位**：`Events.java` 字段 `broadcast`；`BroadcastEmitter.java`。
- **示例**

```js
events.broadcast.emit("hello", "小明");
events.broadcast.on("hello", function (name) {
  toast("你好, " + name);
});
setInterval(function () {}, 1000);
```

## Sensors（传感器）

### 模块概述

注册设备传感器并监听数据变化；不支持模拟传感器数据。脚本退出时会注销监听；持续监听会保持脚本存活。

### 源码定位

| 角色 | 路径 |
|------|------|
| 桥接占位 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/sensors/Sensors.kt`（空对象，实际 API 在 Java 层） |
| 实现 | `app/src/main/java/org/autojs/autojs/runtime/api/Sensors.java` |
| 注册 | `ScriptRuntime.kt` 约第 803 行：`Sensors.augmentWithRuntime(target, this, sensors, true)` |

### API 列表总览

| API / 成员 | 说明 |
|------------|------|
| `register(sensorName[, delay])` | 注册并返回 `SensorEventEmitter` |
| `unregister(emitter)` | 注销 |
| `unregisterAll()` | 全部注销 |
| `ignoresUnsupportedSensor` | 为 true 时不支持传感器也返回空 emitter 并 `emit("unsupported_sensor", name)` |
| `delay.normal` / `ui` / `game` / `fastest` | 采样频率 |

### 详细 API

#### `sensors.register(sensorName[, delay])`

- **参数**：传感器名称（如 `"light"`、`"accelerometer"`）；`delay` 可选，默认 `sensors.delay.normal`。
- **返回值**：`SensorEventEmitter`，不支持且未设置 `ignoresUnsupportedSensor` 时为 `null`。
- **源码定位**：`Sensors.java` `register`。
- **示例**

```js
sensors.register("light").on("change", function (e, light) {
  log(light);
});
```

#### `sensors.unregister(emitter)`

- **参数**：`SensorEventEmitter`。
- **返回值**：void。
- **源码定位**：`Sensors.java` `unregister`。
- **示例**

```js
var s = sensors.register("gravity");
setTimeout(function () { sensors.unregister(s); }, 2000);
```

#### `emitter.on("change", listener)`

- **参数**：事件名 `"change"`；回调参数因传感器类型而异（见官方 [sensors 文档](https://docs.autojs6.com/sensors)）。
- **返回值**：emitter 链式。
- **源码定位**：`SensorEventEmitter.java`（继承 `EventEmitter`）。
- **示例**：见上节光线示例。

#### `sensors.delay` / `sensors.ignoresUnsupportedSensor`

- **说明**：`Delay` 为嵌套类静态常量；`ignoresUnsupportedSensor` 为布尔字段。
- **源码定位**：`Sensors.java` 第 27–31、62–67 行等。
- **示例**

```js
sensors.register("gravity", sensors.delay.game);
sensors.ignoresUnsupportedSensor = true;
sensors.on("unsupported_sensor", function (name) { log(name); });
```

## Recorder（记录器）

### 模块概述

用于**计时**（时间戳差、命名检查点），不是多媒体录制。支持 `save` / `load`、比较、`recorder()` 快捷调用等。

### 源码定位

| 角色 | 路径 |
|------|------|
| 可调用桥接 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/recorder/Recorder.kt`（实现 `Invokable` → `shortcut`） |
| 逻辑 | `app/src/main/java/org/autojs/autojs/runtime/api/Recorder.kt` |
| 注册 | `ScriptRuntime.kt` 约第 800 行：`Recorder(this).augment(target, recorder, true)` |

### API 列表总览

| API | 说明 |
|-----|------|
| `recorder()` / `recorder(key)` / `recorder(func)` | 快捷计时（见 `shortcut`） |
| `save` / `load` | 记录或读取时间戳差 |
| `has` / `remove` / `clear` | 键管理 |
| `isLessThan` / `isGreaterThan` | 与当前时间比较 |

### 详细 API

#### `recorder([key], [timestamp])`（作为函数调用）

- **参数**：重载较多——无参、`key`、或函数（测量函数执行耗时）；见 `Recorder.kt` `shortcut`。
- **返回值**：`number`（时间差或耗时，毫秒语义见实现）。
- **源码定位**：`Recorder.kt`（augment）`invoke` → `shortcut`。
- **示例**

```js
recorder(); // 匿名记录
recorder("step1");
var dt = recorder("step1"); // 与上次同 key 的间隔
```

#### `recorder.save` / `recorder.load`

- **参数**：可选 `key`、`ts`（时间戳）。
- **返回值**：`number`。
- **源码定位**：`Recorder.kt`（runtime）`save` / `load`。
- **示例**（结构见 [recorder 文档](https://docs.autojs6.com/recorder)）

```js
recorder.save("t1");
sleep(1000);
var elapsed = recorder.load("t1");
```

## Media（多媒体）

### 模块概述

音乐播放与媒体文件扫描；播放为后台异步，**脚本若立即结束可能导致播放停止**，常需 `sleep` 保持存活。官方文档另述视频等规划。

### 源码定位

| 角色 | 路径 |
|------|------|
| 桥接占位 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/media/Media.kt` |
| 实现 | `app/src/main/java/org/autojs/autojs/runtime/api/Media.java` |
| 系统音量（音乐流） | `app/src/main/java/org/autojs/autojs/runtime/api/Device.java`（`getMusicVolume` 等） |
| 注册 | `ScriptRuntime.kt` 约第 802 行：`Media.augmentWithRuntime(target, this, media, true)` |

### API 列表总览

| API | 所在模块（源码） |
|-----|------------------|
| `scanFile`、`playMusic`、`musicSeekTo`、`pauseMusic`、`resumeMusic`、`stopMusic`、`isMusicPlaying`、`getMusicDuration`、`getMusicCurrentPosition` | `Media.java` |
| `getMusicVolume`、`getMusicMaxVolume`、`setMusicVolume` | `Device.java`（全局 `device`） |

> 说明：官方文档中常见 `media.getMusicDuration()` 等命名；Java 实现方法名为 **`getMusicDuration` / `getMusicCurrentPosition`**。仓库内**未找到**名为 `adjustVolume` / `adjustMusicVolume` 的 API；调节音量可使用 **`device.setMusicVolume`** 或在 `getMusicVolume()` 与 `getMusicMaxVolume()` 之间换算步进。

### 详细 API

#### `media.scanFile(path)`

- **参数**：`path`（string），本地文件路径。
- **返回值**：void（扫描异步完成）。
- **源码定位**：`Media.java` `scanFile`。
- **示例**

```js
media.scanFile("/sdcard/screenshot.png");
```

#### `media.playMusic(path[, volume, looping])`

- **参数**：路径；音量 0–1；是否循环。
- **返回值**：void；失败抛 `UncheckedIOException`。
- **源码定位**：`Media.java` `playMusic`。
- **示例**

```js
media.playMusic("/sdcard/1.mp3");
media.playMusic("/sdcard/1.mp3", 1.0, true);
```

#### `media.getMusicDuration()` / `media.getMusicCurrentPosition()`

- **参数**：无。
- **返回值**：整型毫秒；未播放时 duration 可能为 0，position 可能为 -1（见 `Media.java`）。
- **源码定位**：`Media.java`。
- **示例**

```js
sleep(media.getMusicDuration());
log(media.getMusicCurrentPosition());
```

#### `media.pauseMusic()` / `media.resumeMusic()` / `media.stopMusic()` / `media.isMusicPlaying()`

- **参数**：无（除内部状态）。
- **返回值**：`isMusicPlaying` 为 `boolean`。
- **源码定位**：`Media.java`。
- **示例**

```js
media.pauseMusic();
media.resumeMusic();
media.stopMusic();
```

#### `device.getMusicVolume()` / `device.getMusicMaxVolume()` / `device.setMusicVolume(i)`

- **参数**：`setMusicVolume` 为整型档位（0～max）。
- **返回值**：当前档位或最大档位。
- **源码定位**：`Device.java` 第 141–175 行附近。
- **示例**

```js
var cur = device.getMusicVolume();
device.setMusicVolume(Math.min(device.getMusicMaxVolume(), cur + 1));
```
