# 08 · 工具与扩展

本文档梳理 AutoJs6 中与 **OpenCC、国际化、标准化、E4X、Polyfill、JS 内建对象扩展（Jsox / Arrayx / Numberx / Mathx）、拼音、NanoID、MIME、Zip、Formatter / Converter / Bytes、摩尔斯电码、媒体信息、系统属性** 等相关的开发要点。内容结合 [AutoJs6 官方文档](https://docs.autojs6.com) 与仓库源码。

**运行时注册参考**（`ScriptRuntime.augment`）：`S13n`、`Converter`（`cvt`）、`Formatter`（`fmt`）、`Arrayx` / `Numberx` / `Mathx` / `Jsox`、`OpenCC`、`Mime`、`SysProps`（`sysprops`）、`Zip`、`NanoID`、`Pinyin`、`Pinyin4j`、`Mediainfo` 等；`util` 下挂载 `MorseCode`（`morseCode`）。详见 `app/src/main/java/org/autojs/autojs/runtime/ScriptRuntime.kt` 约 737–817 行。

## 一、JS 内建扩展（Polyfill、Jsox、Arrayx、Numberx、Mathx）

### 1. Polyfill（代码填泥）

#### 模块概述

Polyfill 用于在引擎未实现某 ES 标准 API 时，在不破坏已有行为的前提下补全实现，以缩小环境差异。

#### 源码定位

- 概念说明以官方文档为准；运行时中 `js_polyfill` 相关引用在 `ScriptRuntime.kt` 内多为注释状态（约 411 行），具体注入方式随版本以 `assets/modules` 与引擎初始化为准。

#### selfAssignmentFunctions / selfAssignmentProperties

无独立全局 `polyfill` 对象；实现以引擎/初始化脚本注入的原型方法为准。

#### API 列表总览

| 能力 | 说明 |
| --- | --- |
| `Array.prototype.at` | 按下标访问（支持负索引） |
| `Array.prototype.flat` | 数组扁平化 |
| `Object.getOwnPropertyDescriptors` | Rhino 较新版本可能已内置 |

#### 详细说明

- **参数 / 返回值**：与 [MDN](https://developer.mozilla.org) 对应标准 API 一致。
- **示例**：

```js
// at 存在时可用
[1, 2, 3].at(-1); // 3
```

- **参阅**：[官方 Polyfill 章节](https://docs.autojs6.com/polyfill)。

### 2. Jsox（`jsox`）— JS 内建对象扩展入口

#### 模块概述

`jsox` 用于按需将 **Mathx / Numberx / Arrayx** 等扩展挂到全局 `Math`、`Number`、`Array` 及其原型上（与 `plugins.extend` / 应用设置「JavaScript 内置对象扩展」配合使用）。

#### 源码定位

- `app/src/main/java/org/autojs/autojs/runtime/api/augment/jsox/Jsox.kt`

#### selfAssignmentFunctions

来自 `Jsox.kt`：

- `extend`
- `extendAll`

**selfAssignmentProperties**：无。

#### API 列表总览

| API | 作用 |
| --- | --- |
| `jsox(...modules)` / `jsox.extend(...)` | 按模块名启用扩展 |
| `jsox.extendAll()` | 启用预设模块列表（`Mathx`, `Numberx`, `Arrayx`） |

#### 详细 API

##### `extend(...args)` / `invoke(...args)`

- **参数**：可变参数，模块名字符串（如 `'Math'`、`'Mathx'`），内部会规范为 `*x` 形式并加载对应类。
- **返回值**：`undefined`。
- **源码**：`Jsox.kt` `extendRhinoWithRuntime`、`extend`。
- **示例**：

```js
jsox('Math', 'Number'); // 或 plugins.extend('Math');
```

##### `extendAll()`

- **参数**：无。
- **返回值**：`undefined`。
- **源码**：`Jsox.kt` `extendAllRhinoWithRuntime`。
- **示例**：

```js
jsox.extendAll(); // 等价于对 Mathx/Numberx/Arrayx 一并 extend
```

### 3. Arrayx（`Arrayx`）

#### 模块概述

扩展数组工具方法；全局有 `Arrayx` 对象，启用内置扩展后同名方法会挂到 `Array.prototype`（参见 [官方文档](https://docs.autojs6.com/arrayx)）。

#### 源码定位

- `app/src/main/java/org/autojs/autojs/runtime/api/augment/jsox/Arrayx.kt`

#### selfAssignmentFunctions

来自 `Arrayx.kt`（`Pair` 第二项为 `AS_JSOX_STATIC` 或 `AS_JSOX_PROTO`）：

| 函数名 | 典型挂载 |
| --- | --- |
| `ensureArray` | 静态（`Arrayx` / `Array`） |
| `distinct`, `distinctBy`, `union`, `intersect`, `subtract`, `differ` | 原型 |
| `sortBy`, `sortByDescending`, `sortDescending`, `sorted`, `sortedDescending`, `sortedBy`, `sortedByDescending`, `shuffle` | 原型 |

**selfAssignmentProperties**：无。

#### API 列表总览

| API | 作用 |
| --- | --- |
| `ensureArray(...o)` | 任一参数非数组则抛错 |
| `distinct` / `distinctBy` | 去重 / 按 selector 去重 |
| `union` / `intersect` / `subtract` / `differ` | 并集 / 交集 / 差集 / 对称差 |
| `sortBy*` / `sorted*` / `sortDescending` | 排序（原地 vs 拷贝） |
| `shuffle` | 随机打乱（原地） |

#### 详细 API（节选）

##### `subtract(arr, other)` / `differ(arr, other)`

- **参数**：两个数组；`subtract` 为 `arr` 相对 `other` 的差集，`differ` 为对称差（见 `Arrayx.kt` 注释）。
- **返回值**：新 `NativeArray`。
- **源码**：`Arrayx.kt` `subtract`、`differ`。
- **示例**：

```js
Arrayx.subtract([1, 2, 3], [2]); // [1, 3]
Arrayx.differ([1, 2], [2, 3]);  // 对称差
```

其余方法（`intersect`、`union`、`sortBy` 等）的参数、返回值与示例见 [arrayx 文档](https://docs.autojs6.com/arrayx)；源码实现见 `Arrayx.kt` 对应 `companion object` 方法。

#### Arrayx API 与源码对照

| API | 参数 | 返回值 | 源码定位 | 示例 |
| --- | --- | --- | --- | --- |
| `ensureArray(...o)` | 可变参数 | `undefined`（失败抛错） | `Arrayx.kt` `ensureArray` | `Arrayx.ensureArray([])` |
| `distinct(arr)` | 数组 | 去重后的新数组 | `distinct` | `[1,1,2].distinct()` |
| `distinctBy(arr, selector)` | 数组、函数 | 按 selector 去重 | `distinctBy` | `Arrayx.distinctBy(arr, e => e.id)` |
| `union(a, ...others)` | 多个数组 | 并集 | `union` | `Arrayx.union(a,b)` |
| `intersect(a, ...others)` | 多个数组 | 交集 | `intersect` | `Arrayx.intersect(a,b)` |
| `subtract(a, b)` | 两个数组 | 差集 | `subtract` | 见上文 |
| `differ(a, b)` | 两个数组 | 对称差 | `differ` | 见上文 |
| `sortBy` / `sortByDescending` | 数组、selector | 原地排序后同一数组引用 | `sortBy` 系列 | 见官方文档示例 |
| `sortDescending` | 数组 | 原地降序 | `sortDescending` | `Arrayx.sortDescending(arr)` |
| `sorted` / `sortedDescending` / `sortedBy` / `sortedByDescending` | 同 sort 系列 | **新数组**，不改变原数组 | `sorted` 系列 | 见官方文档 |
| `shuffle(arr)` | 数组 | 原地乱序 | `shuffle` | `Arrayx.shuffle(arr)` |

#### selfAssignmentFunctions

#### 可调用对象

- `opencc` 实现 `Invokable`：`opencc(s, type)` 等价于 `opencc.convert(s, type)`（见 `OpenCC.invoke` → `convert`）。

#### 详细 API（模式）

- **`convert(s, type)`**
  - **参数**：`s` 字符串；`type` 为 `ConversionType` 或 **字符串**（如 `'S2TWI'`），后者通过反射调用 `*Rhino` 方法。

  - **源码**：`OpenCC.kt` `convert`、`convertRhino`。
- **简写方法**：`s2t(s)`、`t2s(s)` 等，单参数，内部 `ChineseConverter.convert`。
  - **示例**：

```js
opencc.s2t('软件'); // 繁體用字
opencc('软件', 'S2TWI');
```

完整对照表与示例见 [opencc 文档](https://docs.autojs6.com/opencc)。

#### OpenCC 简写 API 一览（单参数）

以下方法均在 `OpenCC.kt` 中实现为「单字符串入参 → 字符串」，内部调用 `cvt(s, ConversionType.*)` 或组合转换（如 `s2jp` = `t2jp` ∘ `s2t`）。`convert` / `opencc(s,type)` 为双参数。

### 9. i18n（国际化）

#### 模块概述

基于 **banana-i18n** 的轻量国际化；从 `assets` 或脚本目录加载 JSON 文案。

#### 源码定位

- `app/src/main/assets/modules/i18n.js`

#### selfAssignmentFunctions / Properties

无 Kotlin 式 `selfAssignment*`；导出为 **构造函数** 实例 `i18n`，原型上挂载方法。

#### API 列表（实例 / 原型）

| 方法 | 作用 |
| --- | --- |

| `bytes(source, fromUnit?)` | 数值 + 可选单位字符串 | 经 `converter.core.Bytes` 转为字节数 | `bytes` / `bytesRhino` | `s13n.bytes(1024, 'KB')` |

## 三、数据工具（Formatter、Converter、Bytes、Mime、NanoID、MorseCode、Zip、Mediainfo、Sysprops）

### 11. Formatter（`fmt`）与 Converter（`cvt`）— 含 Bytes

#### 模块概述

- **`fmt`**：格式化输出，子模块 **`fmt.bytes`** 将字节数格式化为人类可读 **字符串**。
- **`cvt`**：类型转换，子模块 **`cvt.bytes`** 将带单位数值转为 **字节数值**（`number` 等）。

二者在 `ScriptRuntime` 中分别挂载 `formatter.Bytes` / `converter.Bytes`（`BytesFmt` / `BytesCvt`）。

#### 源码定位

- `app/src/main/java/org/autojs/autojs/runtime/api/augment/formatter/Formatter.kt`（占位，`key = "fmt"`）
- `app/src/main/java/org/autojs/autojs/runtime/api/augment/formatter/Bytes.kt`
- `app/src/main/java/org/autojs/autojs/runtime/api/augment/converter/Converter.kt`（`key = "cvt"`）
- `app/src/main/java/org/autojs/autojs/runtime/api/augment/converter/Bytes.kt`
- 核心算法：`app/src/main/java/org/autojs/autojs/runtime/api/augment/converter/core/Bytes.kt`

#### selfAssignmentFunctions / Properties（Bytes 子模块）

`formatter.Bytes` 与 `converter.Bytes` 均包含：

**Properties**：`UNITS`, `AUTO`, `IEC_DIV`, `SI_DIV`。

**Functions**：`strict`, `loose`；主入口为 **可调用对象** `invoke`（即 `fmt.bytes(...)` / `cvt.bytes(...)`）。

#### 详细 API

- **`fmt.bytes(...)`** → **字符串**（`formatter/Bytes.kt` `call` → `CoreBytes.stringRhino`）。
- **`cvt.bytes(...)`** → **数值**（`converter/Bytes.kt` `call` → `CoreBytes.numberRhino`）。
- 参数组合（1～4 个参数、可选 `options` 对象）见两个 `Bytes.kt` 中 `when (argList.size)`；`strict`/`loose` 强制校验策略。

**示例**：

```js
fmt.bytes(1536);           // 如 "1.5 KiB" 形式（依实现与选项）
cvt.bytes('1.5', 'KiB');   // 转为字节数
fmt.bytes.strict(1024);    // 严格模式
```
