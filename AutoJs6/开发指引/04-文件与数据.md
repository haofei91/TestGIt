# 文件与数据

> 本文档覆盖模块：Files（文件）、Storages（储存）、SQLite（数据库）、Base64、Crypto（加密）

## 概述

AutoJs6 在脚本全局提供 `files`、`storages`、`sqlite`、`base64`、`crypto` 等对象，用于读写本地文件、轻量键值存储、SQLite 关系库、Base64 编解码以及对称/非对称加密与摘要。一次性读写可优先使用 `files.read` / `files.write` 等便捷方法；需要流式或频繁读写时使用 `files.open()` 返回的文件对象并在用毕后 `close()`。本地存储基于 `SharedPreferences`，数据以 JSON 字符串序列化，适合配置与非敏感数据。SQLite 封装 `SQLiteOpenHelper`，打开后得到 `Database` 实例，可执行 `execSQL`、`rawQuery` 等。`crypto` 的核心实现位于 `org.autojs.autojs.core.crypto.Crypto`，脚本侧通过 `augment` 挂载；桥接包名为历史拼写 `cryptyo`，以源码为准。

官方文档参考：[Files](https://docs.autojs6.com/files)、[Storages](https://docs.autojs6.com/storages)、[Base64](https://docs.autojs6.com/base64)、[Crypto](https://docs.autojs6.com/crypto)。（SQLite 独立文档页当前不可用，下文以源码为准。）

## Files - 文件

### 模块概述

`files` 对应运行时中的 `org.autojs.autojs.runtime.api.Files` 实例，并由 `augment.files.Files` 补充 `open`（全局函数）、`path`、`join`、`toFile` 等。路径字符串一般会经 `path()` 解析为相对于脚本工作目录的绝对路径（与 `cwd()` 相关）。底层文件操作委托 `org.autojs.autojs.pio.PFiles`。

### 源码定位

- **桥接**：`app/src/main/java/org/autojs/autojs/runtime/api/augment/files/Files.kt`
- **实现**：`app/src/main/java/org/autojs/autojs/runtime/api/Files.kt`
- **全局注册**：`app/src/main/java/org/autojs/autojs/runtime/ScriptRuntime.kt`（约第 793 行）

### API 列表总览

| API | 说明 |
|-----|------|
| `read` / `readBytes` | 读文本 / 读字节 |
| `write` / `writeBytes` / `append` / `appendBytes` | 写文本 / 写字节 / 追加 |
| `copy` / `move` / `rename` | 复制、移动、重命名 |
| `remove` / `removeDir` | 删除文件或空目录 / 递归删目录 |

## Storages - 储存

### 模块概述

`storages` 提供命名空间式的本地存储，底层为 `SharedPreferences`（前缀见 `LocalStorage.NAME_PREFIX`）。值在脚本层通过 `JSON.stringify` / `JSON.parse` 与 `Storage` / `StorageNativeObject` 交互，适合简单配置与列表；**不适合敏感数据**。同一 `name` 多次 `create` 得到独立 JS 对象但共享底层数据（官方文档说明非引用相等）。

### 源码定位

- **桥接**：`app/src/main/java/org/autojs/autojs/runtime/api/augment/storages/Storages.kt`、`Storage.kt`、`StorageNativeObject.kt`
- **存储核心**：`app/src/main/java/org/autojs/autojs/core/storage/LocalStorage.java`
- **全局注册**：`ScriptRuntime.kt` 约第 798 行

## SQLite - 数据库

### 模块概述

`sqlite` 用于打开 SQLite 数据库文件并得到 `Database` 实例（继承 `SQLiteOpenHelper` 并实现 `Closeable`）。支持 `sqlite.open(...)` 以及将 `sqlite` 本身作为函数调用（见 `Invokable`）。打开时使用 `scriptRuntime.files.nonNullPath` 解析路径；可选 `DatabaseCallback` 处理创建/升级/损坏。游标在脚本侧由 `SQLite.CursorWrapper` 包装，便于按列取值与遍历。

### 源码定位

- **桥接**：`app/src/main/java/org/autojs/autojs/runtime/api/augment/sqlite/SQLite.kt`
- **API 辅助**：`app/src/main/java/org/autojs/autojs/runtime/api/SQLite.kt`（`CursorWrapper`）
- **数据库类**：`app/src/main/java/org/autojs/autojs/core/database/Database.java`
- **全局注册**：`ScriptRuntime.kt` 约第 812 行

### API 列表总览

| API | 说明 |
|-----|------|
| `sqlite.open(path[, options, callback])` / `sqlite(path, ...)` | 打开库并返回 `Database` |
| `close` | 关闭连接并从 `closeableManager` 移除 |
| `execSQL` | 执行 SQL（可带绑定参数） |
| `rawQuery` | 原始查询，返回包装后的 Cursor |
| 其它 | `insert` / `update` / `delete` / `query` / `transaction` 等见 `Database.java` |

### 详细 API

#### `sqlite.open(databaseFilePath[, options, callback])`

- **参数**：
  - `databaseFilePath` {string} 非空，经 `files.nonNullPath` 解析为绝对路径。
  - `options` {object} 可选：`version`（默认 `1`）、`readOnly`（默认 `false`），见 `SQLite.Companion.DEFAULT_VERSION` / `DEFAULT_READ_ONLY`。
  - `callback` {DatabaseCallback} 可选：`onCreate` / `onUpgrade` / `onOpen` / `onCorruption`。
- **返回值**：`org.autojs.autojs.core.database.Database` 实例。
- **源码定位**：`37:57:app/src/main/java/org/autojs/autojs/runtime/api/augment/sqlite/SQLite.kt`；`21:23:app/src/main/java/org/autojs/autojs/runtime/api/SQLite.kt`；构造函数 `28:35:app/src/main/java/org/autojs/autojs/core/database/Database.java`
- **示例**：

```js
let db = sqlite.open(files.path('./app.db'), {
    version: 1,
    readOnly: false,
}, {
    onCreate: function (db) {
        db.execSQL('CREATE TABLE IF NOT EXISTS t(id INTEGER PRIMARY KEY, name TEXT);');
    },
    onUpgrade: function (db, oldV, newV) { /* ... */ },
});
```

## Crypto - 加密

### 模块概述

`crypto` 在脚本中映射到 `org.autojs.autojs.core.crypto.Crypto` 单例，提供摘要 `digest`、对称/非对称加解密 `encrypt` / `decrypt`、随机密钥对 `generateKeyPair`，以及构造函数类型 `Key`、`KeyPair`。桥接类位于包名 **`cryptyo`**（历史拼写），仅负责把 Java 类挂到运行时。

### 源码定位

- **桥接**：`app/src/main/java/org/autojs/autojs/runtime/api/augment/cryptyo/Crypto.kt`
- **核心实现**：`app/src/main/java/org/autojs/autojs/core/crypto/Crypto.kt`
- **全局注册**：`ScriptRuntime.kt` 约第 794 行

### API 列表总览

| API / 类型 | 说明 |
|------------|------|
| `digest` | MD5/SHA 等消息摘要，支持 options 指定输入输出格式 |
| `encrypt` / `decrypt` | `Cipher` 加解密，支持 IV、`options.input` / `output` |
| `generateKeyPair` | 随机非对称密钥对（如 RSA） |
| `Key` | 由字节/字符串等构造对称或 RSA 公钥/私钥包装 |
| `KeyPair` | 由已知公钥/私钥数据构造密钥对；`toKeySpec` 用于 DH 等协商 |

### 详细 API

#### `crypto.digest(message[, algorithm, options])`

- **参数**：重载较多（见[官方文档](https://docs.autojs6.com/crypto)）。常见形式：`message` {string}；`algorithm` 如 `'MD5'` / `'SHA-1'`；`options` 可含 `input`（`file` / `base64` / `hex`）、`output`（`bytes` / `base64` / `hex` / `string`）等。
- **返回值**：{string | byte[]} 依 `output` 而定。
- **源码定位**：`85:96:app/src/main/java/org/autojs/autojs/core/crypto/Crypto.kt`
- **示例**：

```js
crypto.digest('hello', 'MD5'); // 32 位十六进制
crypto.digest('hello', 'MD5', { output: 'bytes' });
```

#### `crypto.encrypt(data, key, transformation[, options])`

- **参数**：`data` 明文（string 或字节数组等）；`key` 为 `crypto.Key` 或 `java.security.Key`；`transformation` 如 `'AES'`、`'AES/ECB/PKCS5Padding'`、`'RSA/ECB/PKCS1Padding'`；`options` 含 `iv`、`input`、`output`、`dest`（输出为文件时）等。
- **返回值**：密文字节、`base64`、`hex` 或字符串等（由 `output` 决定）。
- **源码定位**：`99:134:app/src/main/java/org/autojs/autojs/core/crypto/Crypto.kt`
- **示例**：

```js
let key = new crypto.Key('a'.repeat(16));
let enc = crypto.encrypt('hello', key, 'AES', { output: 'base64' });
```

#### `crypto.decrypt(data, key, transformation[, options])`

- **参数**：与 `encrypt` 对称；`options.input` 可区分 `bytes` / `base64` / `hex` 等输入形式。
- **返回值**：解密结果，常配合 `{ output: 'string' }`。
- **源码定位**：`104:134:app/src/main/java/org/autojs/autojs/core/crypto/Crypto.kt`
- **示例**：

```js
let plain = crypto.decrypt(enc, key, 'AES', { input: 'base64', output: 'string' });
```

#### `crypto.generateKeyPair(algorithm[, length])`

- **参数**：`algorithm` {string} 如 `'RSA'`、`'DiffieHellman'`；`length` 默认 `256`（RSA 常用 2048 等以算法要求为准）。
- **返回值**：`KeyPair`（含 `publicKey` / `privateKey`）。
- **源码定位**：`144:154:app/src/main/java/org/autojs/autojs/core/crypto/Crypto.kt`
- **示例**：

```js
let kp = crypto.generateKeyPair('RSA', 2048);
let enc = crypto.encrypt('hello', kp.publicKey, 'RSA/ECB/PKCS1Padding', { output: 'base64' });
```

#### `new crypto.Key(data[, options])`

- **参数**：`data` {string | byte[] | 数组}；`options` 可含 `input`、`keyPair: 'public' | 'private'`（RSA）。
- **返回值**：`Key` 实例，含 `data` 字段与 `toKeySpec(transformation)`。
- **源码定位**：`210:261:app/src/main/java/org/autojs/autojs/core/crypto/Crypto.kt`
- **示例**：

```js
let key = new crypto.Key('0123456789012345'); // 16 字节 AES 密钥材料
```

#### `new crypto.KeyPair(publicKeyData, privateKeyData[, options])`

- **参数**：公钥与私钥的字符串或字节数据；`options` 与 `Key` 类似。
- **返回值**：`KeyPair`。
- **源码定位**：`267:310:app/src/main/java/org/autojs/autojs/core/crypto/Crypto.kt`
- **示例**：

```js
let kp = new crypto.KeyPair(pubBytes, priBytes, { input: 'bytes' });
```
