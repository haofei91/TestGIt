# 类型系统参考

> 本文档汇总 AutoJs6 的复合类型，包括控件类型、图像类型、网络类型、应用类型与基础类型。  
> 官方文档：<https://docs.autojs6.com/>（各类型子页面见各节「在线文档」）。  
> 源码根目录：`/Users/yuhaofei/Documents/coding/github/AutoJs6/`（下文路径均相对该根目录）。

## 概述

AutoJs6 在 Rhino 脚本环境中将 Java/Kotlin 实现类型暴露给 JavaScript：`UiSelector` 用于无障碍树条件查询；`UiObject` / `UiObjectCollection` 表示节点与节点集合；`UiObjectActions` 封装无障碍 `performAction` 的便捷方法；`ImageWrapper` 统一 Bitmap / OpenCV Mat 等图像数据；`WebSocket` 基于 OkHttp；`App` 为常用应用包名枚举；全局 `Color` 与 `colors` 模块配合使用；全局 `Version` 类来自 [version-compare](https://github.com/G00fY2/version-compare) 库，用于语义化版本解析与比较。

## UiSelector - 选择器类型

### 类型概述

`UiSelector` 通过链式调用添加过滤条件（`Filter`），再调用 `find` / `findOne` / `untilFind` 等在无障碍树上检索 `UiObject`。多数条件方法返回 **`UiSelector` 自身**以便链式书写。实现类上约有 **204** 个 `@ScriptInterface` 方法。

**在线文档：** <https://docs.autojs6.com/uiSelectorType>

### 源码定位

| 文件 | 作用 |
|------|------|
| `app/src/main/java/org/autojs/autojs/core/accessibility/UiSelector.kt` | 选择器核心实现 |
| `app/src/main/java/org/autojs/autojs/runtime/api/augment/selector/Selector.kt` | 全局 `selector` 与按方法名包装调用，避免污染全局选择器状态 |

## WebSocket 类型

### 类型概述

基于 OkHttp 的 `okhttp3.WebSocket`，并混入 `EventEmitter` 事件（`on`/`once` 等）。与底层 TCP `Socket` 不同。

**在线文档：** <https://docs.autojs6.com/webSocketType>

### 源码定位

`app/src/main/java/org/autojs/autojs/core/web/WebSocket.kt`；常量等见 `WebSocketFields.kt`。

### 构造与主要 API

| 成员 | 说明 |
|------|------|
| 构造函数 | `WebSocket(scriptRuntime, client, url, ...)`，内部 `newWebSocket` 建连（约 19–41） |
| `send` | 文本 `String` 或 `okio.ByteString` |
| `close` | 多种重载；状态码见文档 `CODE_*` |
| `cancel` | 立即取消 |
| `queueSize` | 待发队列字节数 |
| `request` | 原始 `Request` |
| `rebuild` / `rebuild(max)` | 重连控制（约 44–57） |
| `exitOnClose` | 脚本退出与超时（约 79–87） |
| `on` / `once` | 返回 `WebSocket` 以链式调用（约 76–77） |

**事件常量：** `EVENT_OPEN`、`EVENT_MESSAGE`、`EVENT_TEXT`、`EVENT_BYTES`、`EVENT_CLOSING`、`EVENT_CLOSED`、`EVENT_FAILURE`、`EVENT_MAX_REBUILDS` 等（见 `WebSocketFields.kt` 与文档）。
