# 自动化操控

> 本文档覆盖模块：Global（全局函数）、Automator（自动化）、Keys（按键）、UiSelector（选择器）  
> 对应官方文档：[Global](https://docs.autojs6.com/global) | [Automator](https://docs.autojs6.com/automator) | [Keys](https://docs.autojs6.com/keys)

## 概述

本组能力支撑脚本在 Android 上的**流程控制**（休眠、退出、等待）、**剪贴板与前台组件查询**、**分辨率与坐标换算**、**无障碍与手势自动化**（点击、滑动、全局动作）、以及 **UI 树检索**（选择器、`pickup`/`detect`）。  
官方文档中 Global 章节较完整；Automator / Keys 部分页面仍标有「待补充」，下文在引用官网描述的同时，**以仓库源码为准**补充桥接位置与 Android 实现关系，便于二次开发与排错。

## Global - 全局函数

### 模块概述

`Global` 将脚本常用能力挂到顶级作用域：线程与生命周期（`sleep`、`exit`、`isRunning`）、提示与控制台联动（`toastLog` 等）、剪贴板、当前包名/Activity/组件、轮询等待（`wait` 系）、随机数、屏幕标度与 API/版本校验等。另有 `Species`（类型判断）、`isNullish`（可调用）、`Legacy` 中的 `isObject` 等，以及通过 `GlobalClasses` 暴露的 Java 类引用（`Classes.kt`）。

### 源码定位

- **桥接代码**：`app/src/main/java/org/autojs/autojs/runtime/api/augment/global/Global.kt`（`selfAssignmentFunctions` / `selfAssignmentGetters` 为权威列表）  
- **关联桥接**：`Legacy.kt`、`Species.kt`、`IsNullish.kt`、`Classes.kt`、`GlobalClasses.kt`  
- **`toast`**：`runtime/api/augment/toast/Toast.kt`（`invoke` → `Toast.call`）  
- **实现源码**：`Global.kt` 内联调用 `ScriptRuntime`、`ScreenMetrics`、`Toast`、`Console`、`Selector`、`Auto`、`Shizuku`、`Shell` 等

### 详细 API

#### `sleep(millis)` / `sleep(millisMin, millisMax)` / `sleep(millis, bounds)`

- **签名**（官网）：  
  - `sleep(millis)`：`millis` 为毫秒；返回 `void`。  
  - `sleep(millisMin, millisMax)`：在 `[millisMin, millisMax]` 内随机休眠。  
  - `sleep(millis, bounds)`：`bounds` 为数字字符串，表示在 `millis ±` 范围内随机。  
- **实现**：`Global.sleep` → `scriptRuntime.sleep(...)`；**若在 UI 线程调用会抛错**（`RhinoUtils.isUiThread()`）。  
- **桥接**：`Global.kt` `sleep`。  
- **示例**：

```js
sleep(1000);
sleep(3000, 5000);
sleep(4000, "±1e3");
```

#### `exit` / `stop`

- **签名**：`exit()`、`exit(e)`；`stop()` 无参，等价于 `exit()`（**无** `exit(e)` 对应重载）。  
- **实现**：`scriptRuntime.exit()` 或带异常包装退出。  
- **桥接**：`Global.kt` `exit`、`stop`。  

#### `toast` / `toastLog` / `toastInfo` / `toastWarn` / `toastError` / `toastVerbose`

- **官网**：`toast` 见 [Toast 模块](https://docs.autojs6.com/toast)；`toastLog` 等价于 `toast` + `console.log`（重载与 `toast` 一致）。  
- **实现**：`toast*` 系列在 `Global.kt` 中调用 `Toast.call` 与 `Console.*`；**全局 `toast` 本身**由 `Toast.kt` 的 `augment` 注册为可调用对象。  
- **桥接**：`Global.kt`（`toastLog` 等）；`Toast.kt`（`toast`）。  

```js
toast("hello");
toastLog("logged");
toastInfo("info");
```

#### `random()` / `random(min, max)`

- **官网**：`random()` 同 `Math.random()` ∈ `[0,1)`；`random(min,max)` ∈ `[min,max]` 闭区间。  
- **实现注意**：源码中 **仅一个参数时返回 `NaN`**（`random(minArg)` 未实现），应使用 `random(min, max)` 或 `random()`。  
- **桥接**：`Global.kt` `random`。  

#### `setClip` / `getClip`

- **官网**：`setClip(text)` 设置剪贴板；`getClip()` 读取。Android 10+ 对剪贴板访问有限制。  
- **实现**：`setClip` → `scriptRuntime.clip`；`getClip` 在非空 legacy 结果外，Android Q+ 且悬浮窗权限时尝试 `floaty.getClip()`。  
- **桥接**：`Global.kt`。  

#### `currentPackage` / `currentActivity` / `currentComponent`

- **官网**：返回当前前台包名、Activity 名等（文档标为 A11Y 相关）。  
- **实现**：可选参数指定模式：`accessibility` / `shizuku` / `root` / `auto`（默认 **AUTOMATISM**：依次尝试 Shizuku、Shell、无障碍）。亦可传 `{ by: "..." }`。  
- **桥接**：`Global.kt`；底层分别调用 `Auto`、`Shizuku`、`Shell` 的同名方法。  

#### `wait` / `waitForActivity` / `waitForPackage`

- **官网**：`wait(condition)` 默认超时 10s、间隔 200ms；`limit` &lt; 100 为次数上限，≥100 为毫秒超时；支持 `then`/`else` 回调对象；条件可为函数或 Pickup 选择器。  
- **实现**：`wait` 中条件为函数则直接调用；否则走 `Selector.pickup`；`waitForActivity`/`waitForPackage` **禁止在 UI 线程**执行。  
- **桥接**：`Global.kt`。  

#### `setScreenMetrics(width, height)`

- **官网**（Automator 页）：设定脚本设计时的宽高，用于点击/滑动等坐标缩放。  
- **实现**：`scriptRuntime.setScreenMetrics` 更新 `ScreenMetrics`，影响 `GlobalActionAutomator` 手势路径缩放等。  
- **桥接**：`Global.kt`。  

#### `requiresApi(api)` / `requiresAutojsVersion(version)`

- **官网**：不满足则抛错终止脚本；`requiresAutojsVersion` 支持版本名字符串或版本号。  
- **实现**：`requiresAutojsVersion` 对数字：2–9 走字符串分支；≥461 按 `VERSION_CODE` 比较；字符串用 `Version` 库与 `BuildConfig.VERSION_NAME` 比。  
- **桥接**：`Global.kt`。  

#### `getScaleBases` / `setScaleBaseX` / `setScaleBaseY` / `cX` / `cY` / `cYx` / `cXy`

- **官网**：`cX`/`cY`/`cYx`/`cXy` 详见 [Global 文档](https://docs.autojs6.com/global)（比例、基数、`'9:16'` 字符串等）。  
- **实现**：使用 `ScreenMetrics.deviceScreenWidth/Height` 与 `scriptRuntime.scale`；`cYx`/`cXy` 会 `ensureBasesConsistent()`。  
- **桥接**：`Global.kt`。  

#### `isUiThread`

- **签名**：`isUiThread()` → `boolean`。  
- **实现**：`RhinoUtils.isUiThread()`。  
- **桥接**：`Global.kt`。  

#### `isStopped` / `isRunning` / `notStopped` / `isShuttingDown`

- **签名**：均为无参布尔查询。  
- **实现**：`isStopped`/`isShuttingDown` → `scriptRuntime.isStopped`；`isRunning`/`notStopped` 取反。  
- **桥接**：`Global.kt`。  

#### `WIDTH` / `HEIGHT`

- **官网**：`device.width` / `device.height` 的别名 getter。  
- **实现**：`ScreenMetrics.deviceScreenWidth` / `deviceScreenHeight`。  
- **桥接**：`Global.kt` `selfAssignmentGetters`。  

#### `axios` / `cheerio` / `dayjs` / `i18n`

- **实现**：返回 `scriptRuntime` 上已注入的模块引用。  
- **桥接**：`Global.kt` getter。

## Automator - 自动化

### 模块概述

自动化分为：**无障碍服务**（`auto`、窗口与根节点、`Automator` 全局函数）、**手势分发**（`GlobalActionAutomator` 使用 `AccessibilityService.dispatchGesture`，Android 7.0+）、以及 **Root 多点触摸**（`RootAutomator`）。坐标类操作受 `setScreenMetrics` 与内部 `ScreenMetrics` 缩放影响。

### 源码定位

- **桥接**：`runtime/api/augment/automator/Auto.kt`（可调用 `auto()`、`auto.waitFor`、`auto.setMode` 等）  
- **桥接**：`runtime/api/augment/automator/Automator.kt`（`click`、`swipe`、`back` 等全局函数）  
- **桥接**：`runtime/api/augment/automator/RootAutomator.kt`（`RootAutomator` 构造）  
- **实现**：`core/accessibility/SimpleActionAutomator.kt`（组合 `GlobalActionAutomator`、控件 `ActionTarget`）  
- **实现**：`core/automator/GlobalActionAutomator.kt`（全局动作、`dispatchGesture`、点击/滑动）  

### API 列表总览（全局函数与 `auto`）

| API | 简述 | 返回类型 |
|-----|------|---------|
| `auto()` / `auto(mode)` / `auto(mode, isForcibleRestart)` | 启动/设置无障碍模式 | `undefined` |
| `auto.waitFor` / `waitForService` | 等待服务就绪 | `undefined` |
| `click` / `longClick` | 坐标/文本/边界/控件等多种重载 | `boolean` |
| `press` | 按住指定时长 | `boolean` |
| `swipe` | 滑动（多重重载） | `boolean` |
| `gesture` / `gestures` | 路径手势；`gestureAsync` / `gesturesAsync` 异步 | `boolean` / `void` |
| `scrollUp` / `scrollDown` | 可滚动控件 forward/backward 或按文本/区域 | `boolean` |
| `setText` / `input` | 设置文本 / 追加文本（`input` → `appendText`） | `boolean` |
| `back` / `home` / `recents` / `notifications` / `quickSettings` / `powerDialog` / `splitScreen` | 系统全局动作 | `boolean` |
| `lockScreen` / `takeScreenshot` / `headsethook` | 锁屏、截图、耳机键等 | `boolean` |
| `accessibilityButton` / `accessibilityButtonChooser` / `accessibilityShortcut` / `accessibilityAllApps` | 无障碍相关全局动作 | `boolean` |
| `dismissNotificationShade` | 收起通知栏 | `boolean` |
| `captureScreen` | 截图（Android 11+ 实现分支） | `ImageWrapper` |

### 详细 API

#### `auto`（`Auto.kt`）

- **调用形式**：`auto()`、`auto(false)`、`auto("fast")`、`auto("normal", true)` 等：设置模式、是否强制重启无障碍。  
- **主要属性**：`service`、`windows`、`root`、`rootInActiveWindow`、`windowRoots`、`state`。  
- **方法**：`waitFor`、`setMode`、`setFlags`（`findOnUiThread`、`useUsageStats`、`useShell`）、`setWindowFilter`、`currentPackage`/`Activity`/`Component`（来自 `scriptRuntime.info`）。  
- **实现**：`AccessibilityBridge`、`AccessibilityTool`。  
- **注册**：`ScriptRuntime` 756 行。  

#### `click` / `longClick`

- **签名**（源码 TS 注释）：坐标 `(x,y)`、`[x,y]`、`text[,i]`、`left,top,right,bottom`、`UiObject`、`Rect` 等。  
- **实现**：坐标 → `scriptRuntime.automator.click(x,y)` → `GlobalActionAutomator`；控件 → 优先节点 `click()`，否则点中心坐标。  
- **桥接**：`Automator.kt`。  
- **Android**：`GlobalActionAutomator.click` 用短手势模拟点击。  

#### `press` / `swipe` / `gesture` / `gestures`

- **官网**：`press(x,y,duration)`、`swipe(x1,y1,x2,y2,duration)`、`gesture(duration, [x,y], ...)`、`gestures([delay, duration, points...], ...)`。  
- **实现**：`Automator.kt` 解析多种参数顺序；`gestures` 将数组转为 `GestureDescription.StrokeDescription`（经 `ScreenMetrics` 缩放）。  
- **Android**：`GlobalActionAutomator.dispatchGesture`，同步路径在 `gesturesWithHandler` 中阻塞等待结果。  

#### `scrollUp` / `scrollDown`

- **官网**：无参时最大可滚动区域；`scrollUp(i)` 第 i 个可滚动控件；亦支持文本、四边界。  
- **实现**：`SimpleActionAutomator.scrollForward` / `scrollBackward` / `scrollMaxForward` / `scrollMaxBackward` 使用 `ACTION_SCROLL_FORWARD`/`BACKWARD`。  
- **说明**：**横向** `scrollLeft` / `scrollRight` 不在全局 `Automator.kt` 中，而在控件行为上：`UiObjectActions.scrollLeft`/`scrollRight`（`AccessibilityActionCompat`）。  

#### `setText` / `input`（追加）

- **官网**：`setText([i,]text)` 覆盖；`input` 追加。  
- **实现**：`setText` → `ACTION_SET_TEXT`；`input` → `appendText` → `UiObject.ACTION_APPEND_TEXT`。  
- **桥接**：`Automator.kt` `setText`、`input`。  

#### `back` / `home` / `recents` / `notifications` / `quickSettings` / `powerDialog` / `splitScreen`

- **签名**：无参，`boolean`。  
- **实现**：`SimpleActionAutomator` → `GlobalActionAutomator.performGlobalAction`（如 `GLOBAL_ACTION_BACK`）。  
- **官网**：[Keys 文档](https://docs.autojs6.com/keys) 中与无障碍相关的按键说明可对照理解（实际为全局动作而非普通按键注入）。  

#### `lockScreen` / `takeScreenshot` / `headsethook` / `accessibility*` / `dismissNotificationShade`

- **实现**：`GlobalActionAutomator` 中按 API 级别分支，低版本部分动作 `tryPerformGlobalActionWithLowerApi`。  
- **桥接**：`Automator.kt`。  

#### `captureScreen`

- **实现**：Android R+ 分支通过 `ResultAdapter.wait` 等待截图；更低版本抛 `ScriptException`。  
- **桥接**：`Automator.kt` `captureScreen`。  

#### `RootAutomator`（`RootAutomator.kt`）

- **作用**：在 **Root 或 Shizuku 可用** 时构造原生对象，用于底层注入（具体方法见项目内 `RootAutomatorNativeObject`）。  
- **注册**：`ScriptRuntime` 795 行。  

#### 与「方向键 / DPAD」的关系

- 官网 **Keys** 中的 `Up`/`Down`/`Left`/`Right`/`OK`（大写）等 **Root** 按键在源码中实现于 **`Shell.kt`**，内部调用 `KeyCode` 映射到 `KEYCODE_DPAD_*` / `KEYCODE_DPAD_CENTER`。  
- 工程内 **无** `dpadUp` 等驼峰全局名；若文档使用旧名，请以上述 Shell 函数或 `KeyCode` 为准。

## Keys - 按键

### 模块概述

官方文档描述了 **无障碍全局动作**（如 `back()`）与 **Root 大写函数**（如 `Home()`）以及 `KeyCode` 等。  
在 **AutoJs6 当前源码** 中，`Keys.kt` 仅向全局 **`keys`** 对象注入 **少量键码常量**（`home`/`HOME`、`back`/`BACK`、`menu`/`MENU`、音量键别名），用于脚本读取标准 `KeyEvent` 数值。

### 源码定位

- **桥接**：`app/src/main/java/org/autojs/autojs/runtime/api/augment/events/Keys.kt`  
- **注册**：`ScriptRuntime.kt` 约 760 行：`Keys.augmentWithRuntime`  
- **Root 按键与 `KeyCode`**：`runtime/api/augment/shell/Shell.kt`（`Home`、`Back`、`Up`、`Down`、`Left`、`Right`、`OK`、`KeyCode` 等）  

### API 列表总览

| 名称 | 简述 | 类型 |
|------|------|------|
| `keys.home` / `keys.HOME` | `KEYCODE_HOME` | `number` |
| `keys.back` / `keys.BACK` | `KEYCODE_BACK` | `number` |
| `keys.menu` / `keys.MENU` | `KEYCODE_MENU` | `number` |
| `keys.volumeUp` / `keys.volume_up` / `keys.VOLUME_UP` | `KEYCODE_VOLUME_UP` | `number` |
| `keys.volumeDown` / … | `KEYCODE_VOLUME_DOWN` | `number` |

### 详细说明

- **官网**：完整按键模拟与 **KeyCode 对照表** 见 [Keys 文档](https://docs.autojs6.com/keys)。  
- **与 Automator 全局函数关系**：小写 `back()`、`home()` 等为 **无障碍全局动作**（`Automator.kt`），不经过 `keys` 常量。  
- **示例**（使用常量配合事件 API 时，需结合 `events` 模块，此处仅作数值引用示例）：

```js
// 读取标准键码
console.log(keys.back); // 例如 4
```

## UiSelector - 选择器（概要）

### 模块概述

- **`selector()`**：返回新的 `UiSelector` 实例，用于链式添加筛选条件并在当前无障碍窗口树中 `find`、`untilFind` 等。  
- **全局方法**：`pickup`、`detect`、`existsAll`、`existsOne` 在 `Selector.kt` 中实现，核心逻辑委托 **`core/accessibility/UiSelector.kt`** 与 **`UiObject`**。  
- **注意**：`click`、`longClick`、`scrollDown`、`scrollUp`、`setText` 等已从 **UiSelector 全局方法** 中排除，由 **Automator** 模块占用（见 `Selector.kt` 注释）。  

### 源码定位

- **桥接**：`runtime/api/augment/selector/Selector.kt`（构造时动态挂接 `UiSelector` 上除黑名单外的 Java 方法）  
- **实现**：`core/accessibility/UiSelector.kt`、`core/automator/UiObject.kt`、`UiObjectCollection`  
- **注册**：`ScriptRuntime.kt` 758 行：`Selector(this).augment(target, true, READONLY)` — 全局 **`selector` 为只读**，不可被脚本重写。  

### 与 UiObject 的关系

- **UiSelector**：描述「如何找控件」。  
- **UiObject**：描述「找到的节点」，可在其上调用行为（点击、滚动等），见 **[控件节点 (UiObject)](https://docs.autojs6.com/uiObjectType)**。  
- **类型与成员明细**（链式 API、罗盘、`pickup` 结果类型等）见同目录 **[09-类型系统参考.md](./09-类型系统参考.md)**，本文不重复展开。

auto.waitFor();
