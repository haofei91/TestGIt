# 图像与视觉

> 本文档覆盖模块：Image（图像）、Color（颜色）、OCR（光学字符识别）、Barcode（条码）、QR Code（二维码）、Canvas（画布）

**官方文档入口（在线）：** [Image](https://docs.autojs6.com/image) · [Color](https://docs.autojs6.com/color) · [OCR](https://docs.autojs6.com/ocr) · [Barcode](https://docs.autojs6.com/barcode) · [QR Code](https://docs.autojs6.com/qrcode) · [Canvas](https://docs.autojs6.com/canvas)

---

## 概述

AutoJs6 在脚本层提供 **`images`**（截图、OpenCV 图像处理、找色找图、模板匹配、特征匹配）、**`colors`**（颜色整数/字符串互转、分量读写、相似度）、**`ocr`**（ML Kit / Paddle / Rapid 多引擎文字识别）、**`barcode` / `qrcode`**（ML Kit 条码与二维码识别）、**`canvas`**（基于 `ScriptCanvas` 的 2D 绘制）等能力。图像对象多为包装类型 **`ImageWrapper`**，使用后宜 **`recycle()`**；**`captureScreen()`** 返回的截图在实现上可不手动回收（参见官方 Image 文档说明）。

**运行时注册（节选）：** 在 `ScriptRuntime.kt` 中，`Canvas` → `Images` → `Ocr`（含 `OcrMLKit` / `OcrPaddle` / `OcrRapid`）→ `Barcode` → `QrCode` → `Colors` / `Color` 等于全局作用域注入顺序相邻，便于对照源码。

## Image - 图像

### 模块概述

- **截图：** `requestScreenCapture` / `requestScreenCaptureAsync` 申请 MediaProjection；`captureScreen` 取帧（无参返回 `ImageWrapper`，有路径则保存）。
- **IO：** `read` / `load`、`copy`、`save`、`fromBase64` / `toBase64`、`fromBytes` / `toBytes`、`matToImage`、`imread`（OpenCV Mat）。
- **处理：** `clip`、`resize`、`scale`、`rotate`、`concat`、`grayscale`、`threshold`、`adaptiveThreshold`、`blur`、`medianBlur`、`gaussianBlur`、`bilateralFilter`、`cvtColor` 等（内部 `initOpenCvIfNeeded()`）。
- **找色：** 推荐使用 `findPointByColor` / `findPointsByColor`；`findColor`、`findColorInRegion`、`findColorEquals`、`findAllPointsForColor`、`findMultiColors` 等为兼容旧名的 **deprecated** 别名（见 `Images.kt`）。
- **找图：** `findPointByImage`（推荐）、`findImage` / `findImageInRegion`（别名）、`matchTemplate` → `MatchingResult`。
- **几何/特征：** `findCircles`（霍夫圆）；`detectAndComputeFeatures` + `matchFeatures` → `ImageFeatures` / `ObjectFrame`。
- **说明：** 本仓库 **未检索到** `images.findLines` 或 `findLines` 符号；若需霍夫直线，需自行基于 OpenCV `Mat` 扩展或使用外部脚本。文档要求的「findFeatures」与源码 API 名称 **`detectAndComputeFeatures`** 对应。

### 源码定位

| 层级 | 路径 |
|------|------|
| 桥接 | `.../augment/images/Images.kt`（绝大多数 `images.*` 入口） |
| 实现 | `.../runtime/api/Images.java`、`ImageWrapper.kt`、`ColorFinder.java`、`ImageFeatureMatching.java` |
| 注册 | `ScriptRuntime.kt` 第 762 行附近 |

| `read(path[, strict])` | 读本地图 |

| `fromBytes` / `toBytes` | 字节数组编解码 |

| `resize` / `scale` / `rotate` / `concat` | 几何与拼接 |
| `grayscale` / `threshold` / `adaptiveThreshold` / `cvtColor` | 颜色与阈值 |

### 详细 API

下列 API 均给出：**参数**、**返回值**、**源码定位**、**示例**。

---

#### `images.requestScreenCapture([arg])`

- **参数：** `boolean` 竖/横屏；或 `(width, height)`；或 `NativeObject`（`orientation` / `width` / `height` / `async` 等，见 `requestScreenCaptureInternal`）。
- **返回值：** `boolean`（是否授权成功）。
- **源码定位：** `Images.kt` `requestScreenCapture` / `requestScreenCaptureInternal`；底层 `Images.java` `requestScreenCapture`。
- **示例：**
```js
if (!images.requestScreenCapture()) {
  toast("截图权限失败");
  exit();
}
```

---

#### `images.captureScreen([path])`

- **参数：** 可选 `path`（保存 PNG）。
- **返回值：** 无参时为 `ImageWrapper`；有参时无返回值（保存文件）。
- **源码定位：** `Images.kt` `captureScreen`；`Images.java` `captureScreen()` / `captureScreen(String)`。
- **示例：**
```js
let img = images.captureScreen();
let c = colors.toString(images.pixel(img, 100, 100));
```

---

#### `images.read(path[, strict])`

- **参数：** 文件路径；`strict` 可选。
- **返回值：** `ImageWrapper` 或 `null`。
- **源码定位：** `Images.kt` `read` → `scriptRuntime.images.read`。
- **示例：**
```js
let img = images.read("/sdcard/1.png");
if (img) img.recycle();
```

---

#### `images.load(src)` / `images.loadAsync(src)`

- **参数：** URL 或路径字符串。
- **返回值：** `load` 返回 `ImageWrapper?`；`loadAsync` 返回 Promise 风格对象（内部 `handleAsyncOperation`）。
- **源码定位：** `Images.kt` `load` / `loadAsync`。
- **示例：**
```js
let img = images.load("https://example.com/a.png");
```

---

#### `images.copy(image)`

- **参数：** `ImageWrapper` 或可读路径字符串。
- **返回值：** 新的 `ImageWrapper`。
- **源码定位：** `Images.kt` `copy`；`Images.java` `copy`。
- **示例：**
```js
let b = images.copy(img);
```

---

#### `images.save(image, path[, format, quality])`

- **参数：** 图；路径；格式 `png|jpg|jpeg|webp`；质量 0–100。
- **返回值：** `boolean`。
- **源码定位：** `Images.kt` `save`；`Images.java` `save`。
- **示例：**
```js
images.save(img, "/sdcard/out.jpg", "jpg", 80);
```

---

#### `images.fromBase64(base64)` / `images.toBase64(img[, format, quality])`

- **参数：** Base64 字符串 / 图与可选格式、质量。
- **返回值：** `ImageWrapper` / `string`。
- **源码定位：** `Images.kt` `fromBase64` / `toBase64`。
- **示例：**
```js
let s = images.toBase64(img, "png", 100);
let img2 = images.fromBase64(s);
```

---

#### `images.fromBytes(bytes)` / `images.toBytes(img[, format, quality])`

- **参数：** `byte[]` 或元素为 0–255 的数组 / 图与可选格式、质量。
- **返回值：** `ImageWrapper` / `byte[]`。
- **源码定位：** `Images.kt` `fromBytes` / `toBytes`。
- **示例：**
```js
let buf = images.toBytes(img, "png");
```

---

#### `images.clip(img, x, y, w, h)` / `images.clip(img, region)`

- **参数：** 图；坐标与宽高；或 `[x,y,w,h]` / `Rect` 等 region。
- **返回值：** `ImageWrapper`。
- **源码定位：** `Images.kt` `clip`。
- **示例：**
```js
let sub = images.clip(img, 0, 0, 200, 200);
```

---

#### `images.resize(img, size[, interpolation])` / `images.scale(img, fx, fy[, interpolation])`

- **参数：** 图；`size` 为 `[w,h]` 或单元素；`fx,fy` 为倍数；插值名如 `LINEAR`（见 `parseInterpolation`）。
- **返回值：** `ImageWrapper`。
- **源码定位：** `Images.kt` `resize` / `scale` → `resizeInternal`。
- **示例：**
```js
let r = images.resize(img, [320, 240]);
let s = images.scale(img, 0.5, 0.5);
```

---

#### `images.rotate(img, degree[, cx, cy])`

- **参数：** 图；角度；可选旋转中心（默认图像中心）。
- **返回值：** `ImageWrapper`。
- **源码定位：** `Images.kt` `rotate`；`Images.java` `rotate`。
- **示例：**
```js
let r = images.rotate(img, 90);
```

---

#### `images.concat(img1, img2[, direction])`

- **参数：** 两张图；`direction` 为 `Gravity` 名如 `RIGHT`/`END`（见 `directionToGravityToConcat`）。
- **返回值：** `ImageWrapper`。
- **源码定位：** `Images.kt` `concat`；`Images.java` `concat`。
- **示例：**
```js
let c = images.concat(a, b, "RIGHT");
```

---

#### `images.grayscale(img)`

- **参数：** 图。
- **返回值：** 灰度 `ImageWrapper`（内部 `cvtColor` BGR2GRAY）。
- **源码定位：** `Images.kt` `grayscale`。
- **示例：**
```js
let g = images.grayscale(img);
```

---

#### `images.threshold(img, threshold, maxVal[, type])`

- **参数：** 图；阈值；最大值；类型字符串如 `BINARY`（`parseThresholdType`）。
- **返回值：** `ImageWrapper`。
- **源码定位：** `Images.kt` `threshold`。
- **示例：**
```js
let b = images.threshold(g, 100, 255, "BINARY");
```

---

#### `images.blur` / `images.medianBlur` / `images.gaussianBlur` / `images.bilateralFilter`

- **参数：** 见各函数：`blur(img, ksize[, anchor, type])`；`medianBlur(img, size)`；`gaussianBlur(img, size[, sigmaX, sigmaY, type])`；`bilateralFilter(img[, d, sigmaColor, sigmaSpace, borderType])`（`Images.kt` 中默认 d=0、sigmaColor=40、sigmaSpace=20）。
- **返回值：** `ImageWrapper`。
- **源码定位：** `Images.kt` 对应静态方法。
- **示例：**
```js
images.blur(img, [5, 5]);
images.medianBlur(img, 5);
images.gaussianBlur(img, [5, 5], 0, 0);
images.bilateralFilter(img);
```

---

#### `images.adaptiveThreshold(img, maxValue, adaptiveMethod, thresholdType, blockSize, C)`

- **参数：** OpenCV `adaptiveThreshold` 对应参数；`adaptiveMethod` 如 `MEAN_C` / `GAUSSIAN_C`。
- **返回值：** `ImageWrapper`。
- **源码定位：** `Images.kt` `adaptiveThreshold`。
- **示例：**
```js
images.adaptiveThreshold(g, 255, "GAUSSIAN_C", "BINARY", 11, 2);
```

---

#### `images.cvtColor(img, code[, dstCn])`

- **参数：** 图；`code` 为 OpenCV 颜色码名字符串（如 `BGR2HSV`，映射 `Imgproc.COLOR_*`）；可选目标通道数。
- **返回值：** `ImageWrapper`。
- **源码定位：** `Images.kt` `cvtColor`。
- **示例：**
```js
images.cvtColor(img, "BGR2HSV");
```

---

#### `images.findColor` / `findColorInRegion` / `images.findPointByColor(img, color, options)`

- **参数：** `findPointByColor(image, color, options)`：`options` 可含 `region`、`threshold`；旧式多参为 `x,y,w,h`。
- **返回值：** `Point`（OpenCV `Point`）或 `null`。
- **源码定位：** `Images.kt` `findPointByColorRhino`；`findColor`/`findColorInRegion` 为 deprecated 包装。
- **示例：**
```js
let p = images.findPointByColor(img, "#ff0000", { threshold: 4, region: [0, 0, 200, 200] });
```

#### `images.findColorEquals` / `findPointByColorExactly`

- **参数：** 图；颜色；可选区域（阈值固定为 0 的精确匹配分支）。
- **返回值：** `Point` 或 `null`。
- **源码定位：** `Images.kt` `findPointByColorExactlyRhino`。
- **示例：**
```js
let p = images.findColorEquals(img, "#f64d30");
```

---

#### `images.findAllPointsForColor` / `findPointsByColor`

- **参数：** 图；颜色；`options`（`region`、`threshold`）。
- **返回值：** `NativeArray` 点集。
- **源码定位：** `Images.kt` `findPointsByColorRhino`。

```js
let pts = images.findPointsByColor(img, "#00ff00", { threshold: 8 });
```

---

#### `images.findMultiColors` / `findPointByColors`

- **参数：** 图；首点颜色；路径数组 `[[dx,dy,color], ...]`；`options`。
- **返回值：** `Point` 或 `null`。
- **源码定位：** `Images.kt` `findPointByColorsRhino`；`ColorFinder`。
- **示例：**
```js
let p = images.findPointByColors(img, "#123456", [[10, 20, "#ffffff"]], {});
```

---

#### `images.detectsColor` / `images.detectColor`

- **参数：** `image, color, x, y[, threshold, algorithm]`；`algorithm` 默认 `"diff"`（见 `ColorDetector`）。
- **返回值：** `boolean`。
- **源码定位：** `Images.kt` `detectColorRhino`。
- **示例：**
```js
if (images.detectColor(img, "#fed9a8", x, y, 16, "diff")) { /* ... */ }
```

---

#### `images.findImage` / `findImageInRegion` / `findPointByImage`

- **参数：** 大图；模板；`options` 含 `region`、`threshold`（相似度 0–1）、`weakThreshold`、`level`。
- **返回值：** `Point` 或 `null`。
- **源码定位：** `Images.kt` `findPointByImageRhino`；`Images.java` `findImage`。
- **示例：**
```js
let p = images.findPointByImage(screen, tpl, { threshold: 0.85, region: [0, 0, 500, 500] });
```

---

#### `images.matchTemplate(img, template[, options])`

- **参数：** 大图；模板；`options`：`threshold`、`weakThreshold`、`region`、`level`、`max`、`useTransparentMask`。
- **返回值：** `MatchingResult`（`MatchingResult.kt`）。
- **源码定位：** `Images.kt` `matchTemplate`；`TemplateMatching`。
- **示例：**
```js
let res = images.matchTemplate(img, tpl, { max: 10, threshold: 0.9 });

```

---

#### `images.findCircles(img[, options])`

- **参数：** 灰度或彩色图（内部可转灰度）；`options`：`region`、`dp`、`minDst`、`param1`、`param2`、`minRadius`、`maxRadius`。
- **返回值：** `HoughCirclesResult` 列表（`x,y,radius`）。
- **源码定位：** `Images.kt` `findCircles`（`Imgproc.HoughCircles`）。
- **示例：**
```js
let cs = images.findCircles(img, { param1: 100, param2: 30, minRadius: 10, maxRadius: 80 });
```

---

#### `images.findLines`（**现状说明**）

- **参数 / 返回值：** 本仓库 **无** 名为 `findLines` 的桥接方法（全项目未检索到符号）。
- **源码定位：** 无。
- **示例 / 替代：** 需直线时请使用 OpenCV 在 Java/Kotlin 层扩展，或对 `images.imread` 得到的 `Mat` 自行调用 `Imgproc.HoughLines`（当前 `Images.kt` 未封装）。

---

#### `images.detectAndComputeFeatures`（对应文档中的「findFeatures」）

- **参数：** `image[, options]`：`region`、`scale`、`method`（`SIFT`/`ORB`）、`grayscale` 等（见 `fillDetectAndComputeFeaturesOptions`）。
- **返回值：** `ImageFeatures`（含描述子，见 `ImageFeatures.kt`）。
- **源码定位：** `Images.kt` `detectAndComputeFeatures`；`ImageFeatureMatching.java`。
- **示例：**
```js
let feat = images.detectAndComputeFeatures(scene, { method: "ORB", grayscale: true });
```

---

#### `images.matchFeatures(sceneFeatures, objectFeatures[, options])`

- **参数：** 两个 `ImageFeatures`；`options`：`matcher`、`drawMatches`（调试输出路径）、`threshold`。
- **返回值：** `ObjectFrame`（四顶点）或 `null`。
- **源码定位：** `Images.kt` `matchFeatures`；`ImageFeatureMatching.featureMatching`；`ObjectFrame.kt`。
- **示例：**
```js
let frame = images.matchFeatures(featA, featB, { threshold: 0.75 });
```

## Color - 颜色

### 模块概述

`colors` 提供颜色整数（`0xAARRGGBB`）、十六进制字符串、`Color` 原生对象之间的转换，以及 **R/G/B/A**、**HSV/HSL** 分量读写、**isSimilar** / **isEqual** 等。常量表见 `colors.android` / `colors.css` / `colors.web` / `colors.material` 等（`Colors.kt` 中 `colorTables`）。

官方文档详述见：[Color](https://docs.autojs6.com/color)。**`parseColor`** 在网站文档中为独立方法（参数范围较 `toInt` 更窄）；底层 Android 解析见 `ColorUtils.parseColor` / `core/image/Colors.kt`。

### 源码定位

| 层级 | 路径 |
|------|------|
| 桥接 | `augment/colors/Colors.kt`、`Color.kt`、`ColorNativeObject.kt` |
| 实现辅助 | `core/image/Colors.kt`、`util/ColorUtils.kt` |
| 注册 | `ScriptRuntime.kt` 约 772–773 行 |

### API 列表总览（节选）

`toInt`、`toHex`、`toFullHex`、`toString`、`rgb`、`argb`、`rgba`、`hsv`/`hsva`、`hsl`/`hsla`、`alpha`、`red`、`green`、`blue`、分量 setter、`isSimilar`、`isEqual`、`summary`、`build`、`parseColor`（文档）、`luminance` 等。

### 详细 API（节选）

---

#### `colors.rgb(r, g, b)` / `colors.argb(a, r, g, b)` / `colors.rgba(r, g, b, a)`

- **参数：** 各通道 0–255 或规范允许的范围（ rgba 中 A 可为小数，见实现）。
- **返回值：** 颜色整数 `number`。
- **源码定位：** `Colors.kt` 中 `@RhinoSingletonFunctionInterface` 对应方法；数值封装 `ColorUtils`。
- **示例：**
```js
let red = colors.rgb(255, 0, 0);
let t = colors.argb(128, 255, 0, 0);
```

---

#### `colors.hsv` / `colors.hsl`（及 `hsva` / `hsla`）

- **参数：** H/S/V 或 H/S/L 分量；透明度可选。
- **返回值：** 颜色整数。
- **源码定位：** `Colors.kt`（HSV/HSL 转换使用 Android/AndroidX 工具）。
- **示例：**
```js
colors.hsv(0, 1, 1); // 红
```

---

#### `colors.toString(color[, alpha|length])` / `colors.toInt(color)`

- **参数：** 任意支持的颜色表示；`toString` 重载见官方文档。
- **返回值：** 十六进制字符串 / 整数。
- **源码定位：** `Colors.kt` `toString` / `toInt`。
- **示例：**
```js
colors.toString(0xffff0000);
colors.toInt("#CC5500");
```

---

#### `colors.red` / `colors.green` / `colors.blue` / `colors.alpha`（getter 形式）

- **参数：** 颜色值。
- **返回值：** 通道数值（或 double 形式 `*Double` 变体）。
- **源码定位：** `Colors.kt` `alpha` / `red` / `green` / `blue` 系列。
- **示例：**
```js
colors.red("#FF0000"); // 255
```

---

#### `colors.isSimilar(c1, c2[, options])` / `colors.isEqual(c1, c2)`

- **参数：** 两种颜色；`options` 可含 `threshold`、`algorithm`（见 `Colors.kt` 中相似度逻辑）。
- **返回值：** `boolean`。
- **源码定位：** `Colors.kt` `isSimilar` / `isEqual`。
- **示例：**
```js
colors.isSimilar("#010101", "#020202", { threshold: 10 });
```

## OCR - 光学字符识别

### 模块概述

- **全局调用：** `ocr(...)` 等价于 **`ocr.recognizeText(...)`**（见官方 OCR 页）。
- **模式：** `ocr.mode` 为 `'mlkit' | 'paddle' | 'rapid'`（以 `OcrMode` 为准）；`ocr.tap('paddle')` 切换。
- **方法：** **`detect`** 返回带边界框与置信度的结构化结果；**`recognizeText`** 仅返回字符串数组。
- **子引擎：** **`ocr.mlkit`**、**`ocr.paddle`**、**`ocr.rapid`** 可显式调用，避免依赖当前 `mode`。

### 源码定位

| 文件 | 作用 |
|------|------|
| `augment/ocr/Ocr.kt` | 分发、`recognizeText`/`detect`、`mode`、`summary` |
| `OcrMLKit.kt` | ML Kit 实现入口 |
| `OcrPaddle.kt` | Paddle 选项与插件 |
| `OcrRapid.kt` | Rapid OCR |
| `PaddleOcrEmbeddedEngine.kt` | 嵌入式 Paddle 引擎（按需） |
| `ScriptRuntime.kt` 763–767 | 注册 |

### API 列表总览

| API | 说明 |
|-----|------|
| `ocr(options?)` / `ocr(region)` / `ocr(img, ...)` | 同 `recognizeText` |
| `ocr.recognizeText(...)` | 字符串数组 |
| `ocr.detect(...)` | `OcrResult[]` |
| `ocr.mode` | 读/写引擎 |
| `ocr.tap(mode)` | 切换引擎 |
| `ocr.summary()` | 当前可用模式说明 |
| `ocr.mlkit.*` / `ocr.paddle.*` / `ocr.rapid.*` | 子引擎显式调用 |

### 详细 API

---

#### `ocr.detect(...)` / `ocr.recognizeText(...)`

- **参数：** 无参时内部自动 **`captureScreen`**；或 `ImageWrapper`；或图片路径字符串；或带 `region` / `OcrOptions`（见文档）。
- **返回值：** `detect` → `OcrResult[]`（含 `bounds`、`confidence` 等）；`recognizeText` → **字符串数组**。
- **源码定位：** `Ocr.kt` `dispatchOcrWith`；各 `*Impl` 在 `OcrMLKit.kt` / `OcrPaddle.kt` / `OcrRapid.kt`。
- **示例：**
```js
images.requestScreenCapture();
let img = images.captureScreen();
let texts = ocr.recognizeText(img);
let blocks = ocr.detect(img).filter(o => o.confidence >= 0.8);
```

---

#### `ocr.mode` / `ocr.tap('paddle')`

- **参数：** 模式名字符串或子引擎对象。
- **返回值：** getter 返回当前模式；`tap` 无返回值。
- **源码定位：** `Ocr.kt` `Companion`；`ScriptRuntime` 中 `ocr` 服务。
- **示例：**
```js
ocr.mode = "paddle";
ocr.tap("mlkit");
```

---

#### `ocr.mlkit` / `ocr.paddle` / `ocr.rapid`

- **参数：** 与顶层 `detect`/`recognizeText` 相同，但 **强制** 使用对应引擎（`overrideMode`）。
- **返回值：** 同对应方法。
- **源码定位：** 各 `OcrMLKit.kt`、`OcrPaddle.kt`、`OcrRapid.kt` 中 `recognizeText`/`detect`。
- **示例：**
```js
let a = ocr.paddle.recognizeText(img);
let b = ocr.mlkit.detect(img);
```

> Paddle 模式建议关闭过度节电限制（官方文档提示）。

---

### OCR 必覆盖 API 速查表

| API | 参数（要点） | 返回值 | 源码定位 | 示例 |
|-----|----------------|--------|----------|------|
| `ocr.detect` | 同官方 9 种重载：无参截屏 / `region` / `img` / 路径等 | `OcrResult[]` | `Ocr.kt` + 各引擎 `detectImpl` | `ocr.detect(img)` |

| `ocr.rapid.detect` / `recognizeText` | 强制 Rapid | 同上 | `OcrRapid.kt` | `ocr.rapid.detect(img)` |

## Canvas - 画布

### 模块概述

### 源码定位

- 注册：`ScriptRuntime.kt` 约 761 行 `Canvas(this).augment(target, false)`

### API 列表总览

构造：`new Canvas()`、`new Canvas(bitmap|image)`、`new Canvas(width, height)`。实例方法以官方文档列举的 `drawLine`、`drawRect`、`drawColor`、`getWidth`/`getHeight`、`translate`/`scale`/`rotate` 等为准（委托底层 `android.graphics.Canvas`）。

### 详细 API

---

#### `new Canvas()` / `new Canvas(bitmapOrImage)` / `new Canvas(width, height)`

let cv = new Canvas(1080, 1920);
