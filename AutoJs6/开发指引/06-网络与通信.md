# 网络与通信

> 本文档覆盖模块：HTTP、Web（万维网）、WebSocket

## 概述

AutoJs6 将「发 HTTP 请求」「在应用内嵌网页 / 注入脚本」「长连接 WebSocket」拆成三个方向：

| 能力 | 脚本入口 | 典型用途 |
|------|----------|----------|
| HTTP 客户端 | `http` | REST 调用、下载、表单 / JSON / 多部分上传 |
| 内嵌 WebView | `web`（全局函数） | UI 中展示网页、`inject` 执行页面 JS |
| WebSocket | `WebSocket` 构造 / `web.newWebSocket` | 双向实时通信（底层为 OkHttp WebSocket） |

官方文档入口（可能与实现迭代存在滞后，以源码为准）：

- [HTTP](https://docs.autojs6.com/http)
- [Web（万维网）](https://docs.autojs6.com/web)
- [WebSocket 类型](https://docs.autojs6.com/webSocketType)

## HTTP

### 模块概述

`http` 基于 **OkHttp**，在脚本侧暴露 `get` / `post` / `put` / `delete` 等便捷方法，并统一走 `request` → `buildRequest` 构建 `okhttp3.Request`。同步调用在子线程执行 `Call.execute()`；传入回调时在后台 `enqueue`，回调在脚本线程触发。另提供 `*Async` 变体，通过 `handleAsyncOperation` 在后台执行网络、在 UI 线程包装响应（见 `Http.kt` 中 `requestAsyncRhinoWithRuntime`）。

**PATCH：** 当前桥接层**没有**单独的 `http.patch` 封装；请使用 `http.request(url, { method: 'PATCH', body: ..., headers: ... })`（`RequestBuilderHelper` 按 `options.method` 设置动词，支持任意 OkHttp 支持的 method 与 body 组合）。

### 源码定位

| 文件 | 职责 |
|------|------|
| `Http.kt` | 全部对外 API、`prepareRequest`、`wrapResponse` |
| `RequestBuilder.kt` | URL、`headers`、`method`、超时、`client` 反射配置、`isInsecure` |
| `RequestBuilderHelper.kt` | URL 补全 `http://`、正文 / multipart 解析、函数型 `body` 写 `BufferedSink` |
| `ResponseWrapper.kt` | 将 `okhttp3.Response` 映射为脚本对象字段 |
| `ResponseBodyNativeObject.kt` | `body.string` / `bytes` / `json` / `stream` / `saveToFile` / `close` |
| `HttpSaveResult.kt` | `saveToFile` 的结果对象 |

### API 列表总览

| API | 说明 |
|-----|------|
| `http.buildRequest(url, options?)` | 返回 `okhttp3.Request` |
| `http.request(url, options?, callback?)` | 通用请求；无回调则同步返回包装后的 Response |
| `http.requestAsync(url, options?, callback?)` | 异步任务对象（后台请求 + UI 线程包装） |
| `http.get` / `getAsync` | 固定 `method: GET` |
| `http.head` / `headAsync` | 固定 `method: HEAD` |
| `http.post` / `postAsync` | 默认 `application/x-www-form-urlencoded`，`data` 转表单或按 contentType 处理 |
| `http.postJson` / `postJsonAsync` | `Content-Type: application/json` |
| `http.postMultipart` / `postMultipartAsync` | `multipart/form-data`，`files` 字段 |
| `http.put` / `putAsync` | `PUT`，默认表单 contentType 行为同 post |
| `http.delete` / `del` / `deleteAsync` / `delAsync` | `DELETE`，可带 body |
| `http.__okhttp__` | 内部 `MutableOkHttp`（只读枚举隐藏），用于高级定制 |

### 详细 API

#### `http.buildRequest(url, options?)`

- **参数**
  - `url`：字符串；若不匹配 `https?://` 前缀，会补为 `http://`（见 `RequestBuilderHelper.getUrl`）。
  - `options`：可选，须为普通 JS 对象；见下文「`options` 详解」。
- **返回值**：`okhttp3.Request`（Java 对象）。
- **源码定位**：`Http.buildRequest` / `buildRequestRhinoWithRuntime`（`Http.kt`）。
- **示例**

```js
let req = http.buildRequest('api.example.com/v1', {
  method: 'GET',
  headers: { Authorization: 'Bearer token' },
});
```

#### `http.request(url, options?, callback?)`

- **参数**
  - `url`：同上。
  - `options`：见「`options` 详解」；`prepareRequest` 会读取 `maxRetries`、`cacheBody`、`bodyCacheThresholdBytes` 等并构建 `Call`。
  - `callback`：可选函数 `(response, err) => void`。若提供且满足 Continuation 条件，可与协程式等待配合（见源码注释）。
- **返回值**：无 `callback` 时返回包装后的响应对象；有回调时可能为 `undefined`（异步排队）。
- **源码定位**：`request` / `requestRhinoWithRuntime`（`Http.kt`）。
- **示例**

```js
// 同步
let res = http.request('https://httpbin.org/get', { method: 'GET' });
console.log(res.statusCode);

// PATCH（无单独 http.patch 时）
let patched = http.request('https://httpbin.org/patch', {
  method: 'PATCH',
  contentType: 'application/json',
  body: JSON.stringify({ ok: true }),
});
```

#### `options` 参数详解（与 `buildRequest` / `request` 共用）

| 字段 | 类型 / 含义 | 说明 |
|------|-------------|------|
| `method` | string | 如 `GET`、`POST`、`PUT`、`DELETE`、`PATCH`、`HEAD` 等；`get`/`post` 等便捷方法会强制覆盖或默认。 |
| `headers` | object | 键值对；同一键若多次出现，值可为数组，会展开为多行 header（`RequestBuilderHelper.setHeaders`）。 |
| `contentType` | string | 影响正文编码：`application/x-www-form-urlencoded` 时 `data` 会变为表单；`application/json` 时对对象使用 `JSON.stringify`（见 `fillPostData`）。 |
| `body` | string / `RequestBody` / 函数 | 字符串按 `contentType` 转 `RequestBody`；函数接收 Okio `BufferedSink`，用于流式上传。 |
| `files` | object | 仅 multipart：`postMultipart` 设置 `Content-Type` 与 `files`，值为字符串、`open()` 文件、`[fileName, path]` 或 `[fileName, mime, path]`。 |
| `timeout` | number | 毫秒；读写、连接超时均设为该值（`RequestBuilder.applyOkHttpClientBuilder`）。 |
| `client` | object | 键为 `OkHttpClient.Builder` 方法名，值为参数，经反射调用（无参方法不允许通过此方式调用）。用于配置代理、证书等。 |
| `isInsecure` / `insecure` | boolean | `true` 时信任所有证书并跳过主机名校验（仅当确实需要时慎用）。 |
| `maxRetries` | number | 写入 `MutableOkHttp.maxRetries`（默认见 `Http.DEFAULT_MAX_RETRIES`）。 |
| `cacheBody` | boolean | 为 `true` 时按阈值缓存 `body.string()` / `bytes()` 结果，避免重复读流（`ResponseBodyNativeObject.shouldCache`）。 |
| `bodyCacheThresholdBytes` | number | 缓存阈值字节，默认 8MB。 |

#### `http.get` / `http.post` / `http.put` / `http.delete`（及 `del`）

- **参数（概要）**
  - `get(url, options?, callback?)` — `options` 会被设为 `GET`。
  - `post` / `put` / `delete`：`(url, data?, options?, callback?)`，在对应 method 下调用 `fillPostData`。
- **返回值**：与 `request` 相同规则。
- **源码定位**：`Http.kt` 各 `*RhinoWithRuntime`。
- **示例**

```js
let r = http.get('www.baidu.com');
let r2 = http.post('https://httpbin.org/post', { foo: 'bar' });
```

#### 响应对象（`Response` 脚本包装）

由 `ResponseWrapper.wrap()` 生成，字段如下（**与官方文档中的 Response 概念对应**）：

| 属性 | 含义 |
|------|------|
| `statusCode` | HTTP 状态码（`response.code`） |
| `statusMessage` | 状态短语（`response.message`） |
| `headers` | 小写 header 名为键；多值合并为字符串或数组 |
| `body` | `ResponseBodyNativeObject`：含 `string()`、`bytes()`、`json()`、`stream()`、`saveToFile(path, bufSize?)`、`close()`，以及只读 `contentType` |
| `request` | 对应的 `okhttp3.Request` |
| `url` | `request.url` |
| `method` | `request.method` |

- **源码定位**：`ResponseWrapper.kt`（字段装配）、`ResponseBodyNativeObject.kt`（body 方法）。
- **示例**

```js
let res = http.get('https://httpbin.org/json');
if (res.statusCode === 200) {
  let obj = res.body.json();
  console.log(res.method, res.url);
}
```

#### `body.saveToFile(path, bufferSize?)`

- **参数**：目标文件路径；可选缓冲区大小（默认 8192）。
- **返回值**：`HttpSaveResult`（`code`、`path`、`bytesCopied`、`success`、`error`、`isSuccess()`）。
- **源码定位**：`ResponseBodyNativeObject.saveToFile`、`HttpSaveResult.kt`。

## Web - 万维网

### 模块概述

`web` 模块在 UI 上下文中提供 **可注入脚本的 WebView** 与 **可替换的 WebViewClient**，用于在 Activity 内展示网页并通过 `inject` 与页面交互；**不是** HTTP 客户端模块（与 `http` 分工见官方 [web](https://docs.autojs6.com/web) 说明）。

全局函数由 `Web.kt` 以 `AS_GLOBAL` 注册：`newInjectableWebView`、`newInjectableWebClient`、`newWebSocket`（后者实质创建 `core.web.WebSocket`）。

### 源码定位

| 文件 | 职责 |
|------|------|
| `Web.kt` | `newInjectableWebView` / `newInjectableWebClient` / `newWebSocket` |
| `InjectableWebView.kt` | 继承 `WebView`，初始化 `WebSettings`、`InjectableWebClient`、`WebChromeClient`，暴露 `inject` |

### API 列表总览

| API | 说明 |
|-----|------|
| `newInjectableWebView()` | 使用当前 `activity` 创建 `InjectableWebView` |
| `newInjectableWebView(url)` | 同上并传入初始 URL 字符串（内部 `loadUrl`） |
| `newInjectableWebView(context, url?)` | 显式传入 Android `Context`（脚本里常为 activity），可选 URL |
| `newInjectableWebClient()` | 新建 `InjectableWebClient`（Java），可 `webView.setWebViewClient(...)` |
| `newWebSocket(url)` | 等价于 `new WebSocket(url)`，见 WebSocket 章节 |

### 详细 API

#### `newInjectableWebView(...)` 

- **参数**
  - 无参：使用 `topLevelScope` 上的 `activity` 与当前 Rhino `Context`。
  - 单参为字符串：视为 URL，context 为 `activity`。
  - 单参非字符串：视为 `Context`，无初始 URL。
  - 双参：`(androidContext, url)`，`url` 可为 `null`。
- **返回值**：`InjectableWebView`（可 `addView` 到布局，`loadUrl` / `getSettings` / `inject`）。
- **源码定位**：`Web.newInjectableWebViewRhinoWithRuntime`（`Web.kt`），构造 `InjectableWebView(context, cx, topLevelScope, url)`。
- **示例**

```js
'ui';
ui.layout(<frame id="main" />);
let w = newInjectableWebView();
w.loadUrl('https://www.github.com');
w.inject('alert("hello")');
ui.main.addView(w);
```

```js
'ui';
activity.setContentView(newInjectableWebView('www.github.com'));
```

#### `newInjectableWebClient()`

- **参数**：无。
- **返回值**：`InjectableWebClient`（`org.autojs.autojs.core.web.InjectableWebClient`）。
- **源码定位**：`Web.newInjectableWebClient`（`Web.kt`）。
- **示例**

```js
webView.setWebViewClient(newInjectableWebClient());
```

#### `newWebSocket(url)`

- **参数**：`url` — WebSocket URL（`ws://` / `wss://`）。
- **返回值**：`org.autojs.autojs.core.web.WebSocket` 实例（脚本中即全局 `WebSocket` 的实现对等物）。
- **源码定位**：`Web.newWebSocket` → `CoreWebSocket(scriptRuntime, scriptRuntime.http.okhttp, url)`（`Web.kt`）。
- **示例**：见下一节。

## WebSocket

### 模块概述

脚本侧 **构造函数** `WebSocket` 由 `WebSocket.kt`（augment）实现：

- `new WebSocket(url)`：使用 `scriptRuntime.http.okhttp` 作为 `OkHttpClient` 来源。
- `new WebSocket(client, url)`：**第一参数须为** `MutableOkHttp`（例如脚本里的 `http.__okhttp__`），第二参数为 URL；若第一参数不是 `MutableOkHttp`，实现仍会退回默认 client，且 **URL 取自第二参数、第一参数被忽略**（见 `runtime/.../web/WebSocket.kt` 中 `construct`）。

实现类为 `core.web.WebSocket`，继承 `EventEmitter`，并在构造时调用 `client.newWebSocket` 建立连接。`WebSocketFields` 将 `CoreWebSocket.Companion` 上的常量（事件名、关闭码等）挂到构造函数对象上，便于 `WebSocket.EVENT_OPEN` 等写法。

### 源码定位

| 文件 | 职责 |
|------|------|
| `runtime/.../web/WebSocket.kt` | Rhino 构造封装 |
| `runtime/.../web/WebSocketFields.kt` | 常量代理 |
| `core/web/WebSocket.kt` | 连接、`emit`、`rebuild`、`send`、`close`、`cancel`、事件 |

### API 列表总览

| API / 常量 | 说明 |
|------------|------|
| `new WebSocket(url)` | 使用运行时默认 `MutableOkHttp` 内 `OkHttpClient` |
| `new WebSocket(mutableOkHttp, url)` | 第一参数为 `MutableOkHttp`（如 `http.__okhttp__`），第二参数为 URL |
| `on(event, callback)` / `once` | 继承 `EventEmitter`，返回自身以链式调用 |
| `send(text)` / `send(ByteString)` | 文本或二进制帧 |
| `close(...)` | 转发 OkHttp `close(code, reason)`；重载见源码 |
| `cancel()` | 立即取消，丢弃队列 |
| `rebuild()` / `rebuild(maxTimes)` | 取消后按次数上限重建连接 |
| `request()` | 原始 `okhttp3.Request` |
| `queueSize()` | 待发字节约量 |
| `exitOnClose` | 进程退出时延迟关闭行为（见 `Companion.onExit`） |

事件名常量（与 `core.web.WebSocket` 一致）：`EVENT_OPEN`、`EVENT_MESSAGE`、`EVENT_TEXT`、`EVENT_BYTES`、`EVENT_CLOSING`、`EVENT_CLOSED`、`EVENT_FAILURE`、`EVENT_MAX_REBUILDS`。

### 详细 API

#### 构造函数 `WebSocket(url)` / `WebSocket(mutableOkHttp, url)`

- **参数**
  - 单参：`url` — WebSocket 地址。
  - 双参：`(mutableOkHttp, url)` — `mutableOkHttp` 须为 `MutableOkHttp` 实例（常用 `http.__okhttp__`），`url` 为地址。
- **返回值**：已发起连接的 `WebSocket` 实例（`init` 内即 `build()`）。
- **源码定位**：`WebSocket.construct`（`runtime/.../web/WebSocket.kt`），`WebSocket` 构造（`core/web/WebSocket.kt`）。
- **示例**

```js
let ws = new WebSocket('wss://echo.websocket.events');
// 使用自定义 OkHttp 配置来源（需为 MutableOkHttp）
let ws2 = new WebSocket(http.__okhttp__, 'wss://echo.websocket.events');
```

#### `on(eventName, callback)`

- **参数**
  - `eventName`：字符串，推荐使用 `WebSocket.EVENT_*`。
  - `callback`：依事件不同，参数个数不同（见下表）。
- **返回值**：`WebSocket` 自身（链式调用）。
- **源码定位**：`core/web/WebSocket.on`（覆写 `EventEmitter`）。
- **事件与回调参数（摘自 `WebSocketMessageListener`）**

| 事件 | 常量 | 回调参数 |
|------|------|----------|
| open | `EVENT_OPEN` | `(response, ws)` |
| message（文本或二进制） | `EVENT_MESSAGE` | `(textOrByteString, ws)` |
| 文本 | `EVENT_TEXT` | `(text, ws)` |
| 二进制 | `EVENT_BYTES` | `(bytes, ws)` |
| closing | `EVENT_CLOSING` | `(code, reason, ws)` |
| closed | `EVENT_CLOSED` | `(code, reason, ws)` |
| failure | `EVENT_FAILURE` | `(throwable, response, ws)` |
| max_rebuilds | `EVENT_MAX_REBUILDS` | `(maxRebuildTimes, ws)`（达到重建上限时） |

#### `send(text)` / `send(bytes)`

- **参数**：UTF-8 文本，或 Okio `ByteString`。
- **返回值**：`boolean`（是否入队成功，见 OkHttp 语义）。
- **源码定位**：`core/web/WebSocket.send`。

#### `close(code?, reason?)` / `close(reason)`

- **参数**：关闭码（默认 `CODE_CLOSE_NORMAL`）、原因字符串；或仅传原因字符串。
- **返回值**：`boolean`（是否成功发起优雅关闭）。
- **源码定位**：`core/web/WebSocket.close` 系列。

#### `rebuild()` / `rebuild(maxRebuildTimes)`

- **参数**：无参时仅重建；`rebuild(n)` 会先设置最大重建次数再 `rebuild()`。
- **行为**：`cancel()` 后若未超过最大次数则重新 `newWebSocket`；否则发射 `EVENT_MAX_REBUILDS`。
- **源码定位**：`core/web/WebSocket.rebuild`。
- **示例**

```js
ws.rebuild(3);
```

#### 完整示例

```js
console.setExitOnClose(7000).show();

let ws = new WebSocket('wss://echo.websocket.events');

ws
  .on(WebSocket.EVENT_OPEN, (res, w) => {
    console.log('已连接');
  })
  .on(WebSocket.EVENT_MESSAGE, (msg, w) => {
    console.log('message 帧');
  })
  .on(WebSocket.EVENT_TEXT, (text, w) => {
    console.log('文本:', text);
  })
  .on(WebSocket.EVENT_BYTES, (bytes, w) => {
    console.log(bytes.base64());
  })
  .on(WebSocket.EVENT_CLOSING, (code, reason, w) => {
    console.log('closing', code, reason);
  })
  .on(WebSocket.EVENT_CLOSED, (code, reason, w) => {
    console.log('closed', code, reason);
  })
  .on(WebSocket.EVENT_FAILURE, (err, res, w) => {
    console.error(err);
  });

ws.send('Hello');

setTimeout(() => {
  ws.close(WebSocket.CODE_CLOSE_NORMAL, 'bye');
}, 8000);
```
