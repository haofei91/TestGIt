# 界面与交互

> 本文档覆盖模块：UI（用户界面）、Dialogs（对话框）、Floaty（悬浮窗）、Toast（消息浮动框）、Notice（消息通知）、Console（控制台）

## 概述

AutoJs6 在脚本层提供一整套「界面与交互」能力：用 `ui` 在 `"ui"` 模式下构建 Activity 界面；用 `dialogs` 做同步/异步（含 UI 线程 Promise）弹窗；用 `floaty` 在其他应用上层显示悬浮窗（需悬浮窗权限）；用 `toast` 异步队列显示轻提示；用 `notice` 走系统通知渠道；用 `console` 输出日志并可选浮动控制台窗口。

官方文档入口（与实现对照时请以源码为准）：

- [UI](https://docs.autojs6.com/ui)
- [Dialogs](https://docs.autojs6.com/dialogs)
- [Floaty](https://docs.autojs6.com/floaty)
- [Toast](https://docs.autojs6.com/toast)
- [Notice](https://docs.autojs6.com/notice)
- [Console](https://docs.autojs6.com/console)

## UI - 用户界面

### 模块概述

脚本首行使用 `"ui";` 声明 UI 模式后，可通过 XML（或扩展）描述布局，用 `ui.layout()` 装载界面，并在非 UI 线程用 `ui.run` / `ui.post` 切回 UI 线程更新控件。底层基于 Android `View` 体系，属性与行为可与 [Android View 文档](https://developer.android.google.cn/reference/android/view/View) 对照。

### 源码定位

| 角色 | 路径 |
|------|------|
| Rhino 桥接 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/ui/UI.kt` |
| `ui.Widget` 原型方法 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/ui/UIWidget.kt` |
| 运行时注册 | `app/src/main/java/org/autojs/autojs/runtime/ScriptRuntime.kt`（约第 771 行） |

### API 列表总览

| API | 作用摘要 |
|-----|----------|
| `layout(xml)` | 将 XML 布局 inflate 到当前 Activity 并设为内容视图 |
| `inflate(xml[, parent, attach])` | 将 XML 展开为 `NativeView`，不自动设为全屏布局 |
| `run(action)` | 在 UI 线程执行函数；若已在 UI 线程则直接调用 |
| `post(action[, delay])` | 将函数投递到 UI 队列，可选延迟（毫秒） |
| `statusBarColor(color)` | 设置状态栏背景色 |
| `findView(id)` / `findById(id)` | 在当前 `ui` 根视图上按 id 查找子视图（包装为 `NativeView`） |
| `isUiThread()` | 当前是否处于 UI 线程 |

### 详细 API

#### `layout(xml)`

- **参数**：`xml` — E4X/XML 片段、`Document` 或可转为布局字符串的对象。
- **返回值**：`undefined`。
- **源码定位**：`UI.layout` → `UI.kt` 中 `layout` / `layoutRhinoRuntime`（`setContentViewRhinoRuntime`）。
- **示例**：

```javascript
"ui";
ui.layout(
    <vertical>
        <text id="t" text="Hello"/>
    </vertical>
);
```

#### `inflate(xml[, parent, attachToParent])`

- **参数**：`xml` — 同上；`parent` — 可选 `ViewGroup`；`attachToParent` — 是否附加到父级（默认 `false`）。
- **返回值**：`NativeView`（脚本侧包装视图）。
- **源码定位**：`UI.inflate` / `inflateRhinoRuntime`（`UI.kt`）。
- **示例**：

```javascript
"ui";
var v = ui.inflate(<text text="row"/>);
// 再 setContentView 或加入某容器
```

#### `run(action)`

- **参数**：`action` — JavaScript 函数（无参）。
- **返回值**：函数返回值；若投递到 UI 线程执行，则为同步等待后的结果。
- **源码定位**：`UI.runRhinoRuntime`（`UI.kt`）：若已在 UI 线程则直接 `callFunction`，否则 `uiHandler.post` + `disposable.blockedGet()`。
- **示例**：

```javascript
"ui";
ui.run(function () {
    ui.sample.setText("done");
});
```

#### `post(action[, delay])`

- **参数**：`action` — 函数；`delay` — 可选，延迟毫秒数。
- **返回值**：`boolean`（是否成功 post）。
- **源码定位**：`postRhinoRuntime`（`UI.kt`）。
- **示例**：

```javascript
"ui";
ui.post(function () { toast("on ui"); }, 500);
```

#### `statusBarColor(color)`

- **参数**：`color` — 颜色（Rhino 侧经 `Colors.toIntRhino` 解析）。
- **返回值**：`undefined`。
- **源码定位**：`statusBarColor`（`UI.kt`），内部 `runRhinoRuntime` + `ViewUtils.setStatusBarBackgroundColor`。
- **示例**：

```javascript
"ui";
ui.statusBarColor("#ff0000");
```

#### `findView(id)` / `findById(id)`

- **参数**：`id` — 字符串 ID（与 XML 中 `id` 对应）。
- **返回值**：`NativeView` 或 `null`。
- **源码定位**：`findView` / `findByIdRhinoWithRuntime` / `findByStringIdRhinoRuntime`（`UI.kt`）。
- **示例**：

```javascript
"ui";
ui.layout(<frame><button id="ok"/></frame>);
var b = ui.findView("ok");
```

#### `isUiThread()`

- **参数**：无。
- **返回值**：`boolean`。
- **源码定位**：`isUiThread`（`UI.kt`）→ `RhinoUtils.isUiThread()`。
- **示例**：

```javascript
log(ui.isUiThread()); // 在 UI 模式主线程上通常为 true
```

## Dialogs - 对话框

### 模块概述

`dialogs` 提供基于 Material 对话框的阻塞式交互；在 UI 线程且无回调时，`Dialogs.kt` 会将 `alert` / `confirm` / `rawInput` / `input` / `select` 等包装为 `Promise`。`dialogs.build(properties)` 可拼装复杂对话框并监听事件。

### 源码定位

| 角色 | 路径 |
|------|------|
| Rhino 桥接 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/dialogs/Dialogs.kt` |
| Java API（MaterialDialog 阻塞） | `app/src/main/java/org/autojs/autojs/runtime/api/Dialogs.java` |
| 运行时注册 | `ScriptRuntime.kt` 约第 775 行 |

### API 列表总览

`alert`、`confirm`、`rawInput`、`input`、`prompt`、`select`、`singleChoice`、`multiChoice`、`build`（及 `build` 返回的 `JsDialog` 事件）。

### 详细 API

#### `alert(title[, content, callback])`

- **参数**：`title` — 标题；`content` — 可选正文；`callback` — UI 模式下可选。
- **返回值**：非 UI 线程同步返回；在 UI 线程且无回调时返回 `Promise`（见 `Dialogs.kt`）。
- **源码定位**：`Dialogs.alert` → `Dialogs.kt`；底层 `scriptRuntime.dialogs.alert` → `Dialogs.java`。
- **示例**：

```javascript
alert("提示", "内容");
```

#### `confirm(title[, content, callback])`

- **参数**：同上。
- **返回值**：`true` / `false`；UI 线程无回调时为 `Promise`。
- **源码定位**：`Dialogs.confirm`（`Dialogs.kt` / `Dialogs.java`）。
- **示例**：

```javascript
if (confirm("确定删除吗？")) { /* ... */ }
```

#### `rawInput(title[, prefill, callback])`

- **参数**：`prefill` — 默认文本；`callback` — 可选。
- **返回值**：用户输入字符串，取消为 `null`。
- **源码定位**：`Dialogs.rawInput`（`Dialogs.kt`）；`Dialogs.java#rawInput`。
- **示例**：

```javascript
var s = rawInput("名字", "匿名");
```

#### `input(title[, prefill, callback])`

- **参数**：同 `rawInput`。
- **返回值**：对输入字符串做 `eval` 后的值（与 `rawInput` 不同）。
- **源码定位**：`input` 中 `js_eval`（`Dialogs.kt`）。
- **示例**：

```javascript
var n = dialogs.input("数字", "1+2"); // 得到 3
```

#### `prompt(title[, prefill, callback])`

- **参数**：同 `rawInput`。
- **返回值**：与 `rawInput` 相同（等价转发）。
- **源码定位**：`prompt` → `rawInput`（`Dialogs.kt`）。
- **示例**：

```javascript
prompt("请输入", "");
```

#### `select(title, items[, callback])`

- **参数**：`items` — 字符串数组；`callback` — 可选。
- **返回值**：选中索引，取消为 `-1`。
- **源码定位**：`select`（`Dialogs.kt` / `Dialogs.java`）。
- **示例**：

```javascript
var i = dialogs.select("选一项", ["A","B"]);
```

#### `singleChoice(title, items[, index, callback])`

- **参数**：`index` — 默认选中下标，默认 `0`。
- **返回值**：选中索引或 `-1`。
- **源码定位**：`singleChoice`（`Dialogs.kt` / `Dialogs.java`）。
- **示例**：

```javascript
dialogs.singleChoice("单选", ["a","b"], 1);
```

#### `multiChoice(title, items[, indices, callback])`

- **参数**：`indices` — 预选索引数组。
- **返回值**：选中索引数组；取消为 `[]`（桥接层可能转为 JS 数组）。
- **源码定位**：`multiChoice`（`Dialogs.kt` / `Dialogs.java`）。
- **示例**：

```javascript
dialogs.multiChoice("多选", ["a","b","c"], [0,2]);
```

#### `build(properties)`

- **参数**：`properties` — 配置对象（`title`、`content`、按钮文案、`items` / `itemsSelectMode`：`"select"` | `"single"` | `"multi"`、`inputPrefill`、`progress` 等）。源码中 `itemsSelectMode` 使用 `select`/`single`/`multi`（见 `applyOtherDialogProperties`）。
- **返回值**：`JsDialog`（可 `.on("positive", ...).show()`）。
- **源码定位**：`build`（`Dialogs.kt`）；`JsDialogBuilder.buildDialog()`。
- **示例**：

```javascript
dialogs.build({
    title: "标题",
    content: "正文",
    positive: "确定",
    negative: "取消"
}).on("positive", function () { toast("ok"); }).show();
```

## Floaty - 悬浮窗

### 模块概述

在获得「在其他应用上层显示」权限后，可通过 `floaty.window` / `floaty.rawWindow` 创建悬浮窗；脚本结束时通常由运行时关闭窗口（`Floaty.closeAll`）。非 UI 线程更新控件需配合 `ui.run`。

### 源码定位

| 角色 | 路径 |
|------|------|
| Rhino 桥接 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/floaty/Floaty.kt` |
| 实现 | `app/src/main/java/org/autojs/autojs/runtime/api/Floaty.kt` |
| 核心窗口 | `app/src/main/java/org/autojs/autojs/core/floaty/` |
| 运行时注册 | `ScriptRuntime.kt` 约第 797 行 |

### API 列表总览

| API | 说明 |
|-----|------|
| `window(layout)` | 带调整大小/位置控件的悬浮窗 |
| `rawWindow(layout)` | 无额外控件，可全屏等 |
| `closeAll()` | 关闭当前脚本所有悬浮窗（UI 线程同步关闭） |
| `hasPermission()` | 是否已有悬浮窗权限（文档中偶见「check」表述，源码方法名为 **hasPermission**） |
| `requestPermission()` | 请求权限 |
| `ensurePermission()` | 无权限则抛错 |

### 详细 API

#### `window(layout)`

- **参数**：`layout` — E4X XML 字符串或 XML 对象（与 `wrap` 中 `toXMLString` 一致）。
- **返回值**：代理对象，包装 `JsResizableWindow`，子视图通过 `window.id` 访问。
- **源码定位**：`Floaty.window`（`augment/floaty/Floaty.kt`）→ `scriptRuntime.floaty.window`（`Floaty.kt`）。
- **示例**：

```javascript
var w = floaty.window(
    <frame><text id="t">hi</text></frame>
);
ui.run(function () { w.t.setText("ok"); });
```

#### `rawWindow(layout)`

- **参数**：同 `window`。
- **返回值**：`JsRawWindow` 代理。
- **源码定位**：`rawWindow`（`augment/floaty/Floaty.kt` / `Floaty.kt`）。
- **示例**：

```javascript
var w = floaty.rawWindow(<frame><text id="t"/></frame>);
w.setPosition(100, 200);
```

#### `closeAll()`

- **参数**：无。
- **返回值**：实现中返回 `closeAll()` 的同步结果（集合清空）。
- **源码定位**：`Floaty.closeAll`（`runtime/api/Floaty.kt`）：在 UI 线程同步 `close` 各窗口。
- **示例**：

```javascript
floaty.closeAll();
```

#### `hasPermission()`（文档中的「检查权限」）

- **参数**：无。
- **返回值**：`boolean`。
- **源码定位**：`hasPermission`（`augment/floaty/Floaty.kt`）→ `DisplayOverOtherAppsPermission.has()`。
- **说明**：若习惯称「checkPermission」，请以源码为准使用 `floaty.hasPermission()`。

#### `requestPermission()`

- **参数**：无。
- **返回值**：`undefined`。
- **源码定位**：`requestPermission`（`augment/floaty/Floaty.kt`）。
- **示例**：

```javascript
if (!floaty.hasPermission()) floaty.requestPermission();
```

## Toast - 消息浮动框

### 模块概述

全局可调用 `toast(...)`（模块 `Toast` 实现 `Invokable`），消息进入队列异步显示；支持 `long`/`short`、`forcible` 覆盖；`toast.dismissAll()` 清空队列。详见 [Toast 文档](https://docs.autojs6.com/toast)。

### 源码定位

| 角色 | 路径 |
|------|------|
| 桥接 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/toast/Toast.kt` |
| 参数解析 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/toast/ToastParser.kt` |
| 运行时注册 | `ScriptRuntime.kt` 约第 801 行 |

### API 列表总览

- `toast(message[, isLong[, isForcible]])` 等重载
- `toast.dismissAll()`

### 详细 API

#### `toast(message)`（及重载）

- **参数**：`message` — 文本（`undefined`/`null` 会格式化为字符串）；可选 `isLong`、`isForcible`（见 `ToastParser` 与官方文档）。
- **返回值**：`undefined`（异步展示）。
- **源码定位**：`Toast.call` → `ToastParser.show` → `ScriptToast.enqueueToast`（`Toast.kt` / `ToastParser.kt`）。
- **示例**：

```javascript
toast("hello");
toast("long msg", "long");
toast("now", "short", "forcible");
```

#### `toast.dismissAll()`

- **参数**：无。
- **返回值**：`undefined`。
- **源码定位**：`Toast.dismissAll` → `ScriptToast.dismissAll`（`Toast.kt`）。
- **示例**：

```javascript
toast.dismissAll();
```

## Notice - 消息通知

### 模块概述

`notice(...)` 发送系统通知，返回通知 ID；支持多重重载与 `notice.config({...})` 修改默认行为；`notice.channel` 下挂渠道创建与管理（Android O+）。

### 源码定位

| 角色 | 路径 |
|------|------|
| 桥接 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/notice/Notice.kt` |
| 渠道 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/notice/Channel.kt` |
| 运行时注册 | `ScriptRuntime.kt` 约第 805–807 行（`Notice` + `NoticeChannel` 挂到 `notice`） |

### API 列表总览

- `notice(...)` 多种重载
- `notice.config(options)`
- `notice.channel.create(...)`、`remove`、`contains`、`get`、`getAll` 等

### 详细 API

#### `notice(options)` / `notice(content[, options])` / `notice(title, content[, options])` 等

- **参数**：见 [Notice 文档](https://docs.autojs6.com/notice)；可选 `channelId`、`notificationId`、`bigContent`、`isSilent`、`intent`、`autoCancel` 等（`Notice.kt` 中 `invoke`）。
- **返回值**：`number` — 通知 ID。
- **源码定位**：`Notice.invoke`（`Notice.kt`）；底层 `NotificationUtils.notice`。
- **示例**：

```javascript
notice({ title: "t", content: "c", isSilent: true });
notice("hello", { channelId: "my_channel" });
```

#### `notice.config(options)`

- **参数**：`options` — 与 `scriptRuntime.notice.config` 可写属性对应的键值对象；`null` 值会重置为默认值（见实现）。
- **返回值**：`undefined`。
- **源码定位**：`Notice.config`（`Notice.kt`）。
- **示例**：

```javascript
notice.config({ useDynamicDefaultNotificationId: false });
```

#### `notice.channel`（`Channel.kt`）

- **常用方法**：
  - `notice.channel.create(id, options)` / `create({ id: ..., ... })` — 创建或更新渠道（Android O+）。
  - `createIfNeeded`、`remove`、`contains`、`get`、`getAll`。
- **源码定位**：`Channel.kt`。
- **示例**：

```javascript
notice.channel.create("my_channel", {
    name: "New message",
    importance: "default",
});
notice("hi", { channelId: "my_channel" });
```

## Console - 控制台

### 模块概述

`console` 将日志写入运行时控制台（`ConsoleImpl`），并可 `show`/`hide` 浮动日志窗口。`console.build({...})` 批量调用 `setSize`、`setPosition` 等 setter。日志方法多参数经 `Util.formatRhino` 格式化。

### 源码定位

| 角色 | 路径 |
|------|------|
| Rhino 桥接 | `app/src/main/java/org/autojs/autojs/runtime/api/augment/console/Console.kt` |
| 实现 | `app/src/main/java/org/autojs/autojs/core/console/ConsoleImpl.kt` |
| 接口 | `app/src/main/java/org/autojs/autojs/runtime/api/Console.kt` |
| 运行时注册 | `ScriptRuntime.kt` 约第 787 行 |

### API 列表总览

日志：`log`、`error`、`warn`、`info`、`verbose`、`assert`、`time`、`timeEnd`、`trace`（属性）、`print`  
窗口：`show`、`hide`、`clear`、`build`、`setTitle`、`setSize`、`setPosition`、`setBackgroundColor`、`setContentTextSize`（日志区字号）等

### 详细 API

#### `log(data, ...args)`

- **参数**：可变参数，经 `Util.formatRhino(*args)` 格式化。
- **返回值**：`void`。
- **源码定位**：`Console.log`（`augment/console/Console.kt`）→ `scriptRuntime.console.log` → `ConsoleImpl` / `AbstractConsole`。
- **示例**：`console.log("v=%d", 42);`

#### `error(data, ...args)`

- **参数**：同上。
- **返回值**：`void`。
- **源码定位**：`Console.error`（`Console.kt`）；`ConsoleImpl` 对 `Throwable` 会附加栈（见 `ConsoleImpl.kt`）。
- **示例**：`console.error("failed");`

#### `warn(data, ...args)`

- **参数**：同上。
- **返回值**：`void`。
- **源码定位**：`Console.warn`（`Console.kt`）。
- **示例**：`console.warn("warn %s", "x");`

#### `info(data, ...args)`

- **参数**：同上。
- **返回值**：`void`。
- **源码定位**：`Console.info`（`Console.kt`）。
- **示例**：`console.info("info");`

#### `verbose(data, ...args)`

- **参数**：同上。
- **返回值**：`void`。
- **源码定位**：`Console.verbose`（`Console.kt`）。
- **示例**：`console.verbose("dbg");`

#### `assert(value[, message])`

- **参数**：`value` — 布尔或函数（函数则调用后转布尔）；`message` — 可选，默认 `AssertionError` 类名。
- **返回值**：`console` 代理对象（链式）。
- **源码定位**：`Console.assert`（`Console.kt`）→ `scriptRuntime.console.assertTrue`；接口声明见 `runtime/api/Console.kt`。
- **示例**：

```javascript
console.assert(1 === 1, "fail");
```

#### `time([label])`

- **参数**：`label` — 可选计时器标签。
- **返回值**：`undefined`。
- **源码定位**：`Console.time` → `scriptRuntime.consoleTimeTable.save`（`Console.kt`）。
- **示例**：

```javascript
console.time("op");
console.timeEnd("op");
```

#### `timeEnd([label])`

- **参数**：`label` — 可选，需与 `time` 对应。
- **返回值**：`undefined`。
- **源码定位**：`Console.timeEnd` → `consoleTimeTable.print`（`Console.kt`）。
- **示例**：见上。

#### `trace`（属性，可调用的栈追踪函数）

- **参数**：内部 `BaseFunction`：消息 + 可选级别字符串或 `Log` 级别数值（见 `mCaptureStack`）。
- **返回值**：无直接文档化返回值（副作用为输出日志）。
- **源码定位**：`selfAssignmentProperties` 中 `trace` → `mCaptureStack`（`Console.kt` 约第 58–80、82–84 行）。
- **示例**：`console.trace("stack here");`

#### `print(data, ...args)`

- **参数**：可变参数，格式化后以 `Log.DEBUG` 级别写入。
- **返回值**：`void`（实现中调用 `scriptRuntime.console.print`）。
- **源码定位**：`Console.print`（`Console.kt`）。
- **示例**：`console.print("p");`

```javascript
console.show();
```

#### `hide()`

#### `clear()`

#### `build(options)`

- **参数**：`options` — 对象；键名映射到 `Configurator` 存在的 `setXxx`/`isXxx`（见 `Console.build` 内反射查找）。
- **返回值**：`ConsoleImpl.Configurator`，通常再调用 `.show()`。


#### `setTitle(title)`

- **参数**：`title` — 字符串。
- **返回值**：`console` 代理对象。
- **源码定位**：`Console.setTitle`（`Console.kt`）→ `ConsoleImpl.setTitle`。

#### `setSize(width, height)`

- **参数**：宽、高 — 数值（像素或相对屏幕比例，见 `DisplayUtils.toRoundDoubleX/Y`）。

- **参数**：`x`, `y` — 窗口位置。

- **参数**：`color` — `OmniColor` 可解析形式，经 `S13n.color`。

#### `setContentTextSize(size)`（对应需求中的日志字号；源码无 `setLogSize`）

- **参数**：`size` — 数字，单位 **sp**，仅影响浮动窗口**日志区域**字号（不影响全屏日志 Activity）。
- **返回值**：`console` 代理对象。
- **源码定位**：`Console.setContentTextSize`（`Console.kt`）→ `ConsoleImpl.setContentTextSize`。
